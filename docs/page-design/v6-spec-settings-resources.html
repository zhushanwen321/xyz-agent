对比度修正（M1）

资源项描述文字（item.description）当前用 --neutral-dim #7d8494，在 --bg-card #22242c 上对比度仅 4.13:1，不过 WCAG AA（4.5:1）。v6-spec-tokens.html §3 的声明基于 --bg #1a1b1f（4.62:1）成立，但资源项背景是 bg-card（更浅），需重新核算。修正：迁 --neutral-mid #9ca3af（bg-card 上 6.10:1 过 AA）。同步修正 v6-spec-settings.html §5 set-desc 的同类错误（set-desc 亦用 neutral-dim）。
