Layer A · 加载路径总览（项目 / 全局分组）

单一 bg-card 容器内按作用域分两组：「项目目录」（per-project，仅当前项目生效）+「全局目录」（global，所有项目生效）。两组各自独立管理：行尾 ↑↓ 调整组内优先级（靠前覆盖靠后）+ 移除（ghost danger）。系统内置目录（~/.xyz-agent/skills）锁定在项目目录组顶部（Checkbox disabled + lock，不可移不可关）。底部「从其他 Agent 导入」入口（详见 §4）。路径用真实 ~/.xyz-agent/skills（skills）或 ~/.xyz-agent/agents（agents）。

存储 单一 paths 数组 v6 projectPaths + globalPaths 两字段 排序 拖拽手柄 v6 ↑↓ 上下移动按钮 分组 项目目录 / 全局目录 视觉分隔 优先级 项目目录 > 全局目录 
// LoadPaths 存储模型（v6：单一数组拆两字段）
interface LoadPathsConfig {
  // 项目目录：仅当前项目生效（含系统锁定目录，始终在前）
  projectPaths: string[]
  // 全局目录：所有项目共享
  globalPaths:  string[]
}

// pi 启动时合并两数组：项目目录在前，全局在后；去重保留首次出现位置
function resolveLoadPaths(cfg: LoadPathsConfig): string[] {
  return dedupe([...cfg.projectPaths, ...cfg.globalPaths])
}
// 优先级语义：项目目录 > 全局目录（同名资源取靠前目录的版本）

上下移动排序

排序交互从拖拽改为 ↑↓ 按钮（拖拽在小列表里手感差、易误触）。每行行尾提供 ↑（上移）+ ↓（下移）两个 ghost icon 按钮（h-8 w-8），点击即时在组内交换相邻位置，点击即 emit 持久化（零回路）。组首行的 ↑ 与组末行的 ↓ disabled。系统锁定目录（项目目录组顶部）无 ↑↓ 按钮（不可排序）。三态：default（hover/focus 显按钮）/ moving（被移行 accent-soft 微染 120ms）/ disabled（边界行 opacity .35 不可点）。

空态三要素（设计系统 §7）：图标（neutral-faint）+ 一句说明 + 一个 Primary 入口。两类空态：① 全来源空（无任何资源）——指向「添加目录」或「刷新」；② 单 tab 筛选空（该来源无资源）——指向「切换 tab」。错误态：扫描失败 / 检测失败——danger soft 条 + 原因 + 下一步。文案用 neutral-mid（过 AA）。
