§2

拖拽排序交互

可选目录用原生 HTML5 拖拽，纯本地状态驱动（拖拽只改 localDirs 即时生效，dragend 一次性 emit 持久化）。四态可视化：default（可拖）/ dragging（被拖行 opacity .4）/ drop-target（目标行上方 2px accent 指示线 + accent-soft 微染）/ locked（强制行 grip 不可拖 opacity .3）。GripVertical 16px 是唯一拖拽手柄。

无障碍: grip 加 aria-label「拖拽排序」；纯拖拽场景下另提供键盘上下移的备用入口（未来增强）
§3

添加自定义路径

Input（xyz-ui，placeholder /absolute/path/to/dir，font-mono）+ Button default（「添加」，verb+object）。回车或点按钮触发校验：非空 + 去重（与现有 path 字面相等则报「路径已存在」）。错误态 Input 边框转 danger，下方 neutral-mid 错误文案配警示图标。新路径默认 enabled=true，append 到列表末尾（最低优先级，可再拖排序）。

§4

§7

空态 / 错误态

空态三要素（设计系统 §7）：图标（neutral-faint）+ 一句说明 + 一个 Primary 入口。两类空态：① 全来源空（无任何资源）——指向「添加目录」或「刷新」；② 单 tab 筛选空（该来源无资源）——指向「切换 tab」。错误态：扫描失败 / 检测失败——danger soft 条 + 原因 + 下一步。文案用 neutral-mid（过 AA）。

全空
