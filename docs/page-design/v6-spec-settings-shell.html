每行 label 下新增 12px 描述文字（i18n 新增 *.desc keys），解释该选项作用。label 去 uppercase tracking-wider（AI slop tell），改 font-medium 大小写混合。行结构：左 label+desc 块 / 右控件。★ 对比度修正：desc 原计划用 --neutral-dim，审查发现其 on bg-card 仅 4.13:1（不过 AA 4.5），故改用 --neutral-mid（6.10:1 过 AA）。

desc 一致性: SystemPage 已有部分 hint（autoRenameSessionHint），v6 统一为 *.desc 并推广到全部 *Page
