§1

三栏拓扑总览

AppShell 是三栏组合根：aside（侧栏画布）｜app-nav-controls（浮层导航）｜main-panel（surface 浮起，含 Workspace）+ 可选 drawer（与 main 共享同一 surface 浮起体，从 main 右缘生长挤占 main 宽度，详见 §7）。v6 保留 v3 的三栏拓扑不变（§1.1#2），底色语义：aside = 画布色（--bg-sunken），与窗口底同色融合；main-panel + drawer 共享 surface 浮起（同一 border + shadow 外壳、同 --surface 底色），是唯一带 border + shadow 的浮起体。窗口整体落在 stage 深底 #131316 上（app-shell p-3 间隙显露）。view 路由简化：main-panel 仅 chat（Workspace），Overview 概览页已移除（sidebar sessions tab 已覆盖会话列表需求）。

§2

三层明度体系

v6 验收基准之一：三层背景肉眼可辨（§9）。从深到浅：stage 深底 #131316（窗口底，app-shell padding 背景，不新增 token）→ 画布 #1a1b1f（--bg-sunken = --bg，侧栏落色，与窗口同色融合）→ surface 浮起 #272830（主面板 + drawer 共享，焦点区）。--bg-sunken 语义变更：原 visual-modernization 用 color-mix(bg 97%, black) 把侧栏往黑推导致发脏，v6 改为与画布同色，靠主面板浮起表达层级。drawer 不再独立成层——它与 main 共享同一 surface 浮起体（§7），从 main 右缘生长挤占 main 宽度。不嵌套第四层。

现 bg-sunken color-mix 往黑推（发脏） v6 bg-sunken = bg（同色融合） v6 三层明度肉眼可辨

traffic-light 安全区

aside-region 恒定 padding-top: 52px 留出红黄绿落位的安全区，三平台统一、全屏也保留（mac 全屏 hover 时系统下拉覆盖层落进这块留白）。mac 由主进程 titleBarStyle:'hidden' + trafficLightPosition:{x:16,y:26} 精确控制（不用 hiddenInset）；win/linux 自绘彩色圆点 left:16px top:26px mimic mac，三平台左上视觉统一。v6 修订：① win/linux hover 符号弃用 lucide（8px 极小尺寸抗锯齿差、高 DPI 缩放下模糊溢出），改手绘 SVG path 针对小尺寸精确设计 stroke-width，去 border；② 挂载点从 AsideRegion 提升到 AppShell 层（避免折叠态 aside 归零改变定位基准）。注：mac 红黄绿由 OS 绘制，无法随折叠态位移，故 traffic-light 恒定 left:16px，不随侧栏折叠让位。

§7

drawer 一体化生长

drawer 与 main-panel 共享同一个 surface 浮起体——drawer 不是独立浮层，而是从 main 右缘生长出来、挤占 main 宽度的一部分。底色同为 --surface，保留弱投影 0.16（--shadow-drawer）+ 同色体分隔（去 border-l 硬分隔），靠 main header 下方的 hairline 内嵌分层（drawer header 同 surface 底 + hairline 分隔，方案 G）表达边界。展开/收起是宽度过渡：main 内容区收缩 + drawer 宽度生长同步（320ms ease），形成「从 main 内部拉出」的一体感。

现 drawer 独立画布色 + shadow-drawer 投影 v6 drawer 共享 surface（与 main 一体） v6 从 main 右缘生长挤占 + 320ms 过渡
