§6

shadow token 应用

覆盖层的「浮起」靠 shadow token 表达（§2.4）。两个主 token：①--shadow-2: 0 8px 24px rgba(0,0,0,0.4) 用于全部浮层/modal（SearchModal 浮层 / ConfirmDialog / AskUserOverlay / popover）；②--shadow-glow: 0 0 0 3px rgba(79,142,247,0.25) 用于 focus 态（输入框聚焦环）。另：--shadow-drawer: -12px 0 24px rgba(0,0,0,0.25) 用于 SideDrawer 左投影分隔（与 overlays 同属覆盖层家族，此处一并标注）。v6 不新增 shadow token，仅收敛任意值到语义 token。
