§1.5

瞬时浮层与系统提示

MessageStream 容器内的辅助/瞬时元素——它们不是 turn 内块（trace/ChangeSet），而是承载在 scrollEl 直接子节点上的视图层分支。v6 补全：spec 原先只画了容器滚动结构（§1），这 7 类实际存在、用户可见、且无其他 spec 承接的元素在此补齐。分三类：① 空态/导航（空态欢迎语、加载更多、回到底部）② 持久历史标记（SystemNotice 虚拟化穿插）③ 瞬时浮层（compacting/dispatching/ForkNotice，abs 定位读 vlistBottom 堆叠）。落点：MessageStream.vue template。

现状 7 类元素已在代码中，spec 未画 v6 spec 补全展示 + 定位/z-index 标注 [欠考虑] 瞬时浮层堆叠顺序需文档化 [v6 统一] ④⑤⑦ 瞬时浮层视觉统一为浮层卡片骨架（差异仅 leading icon）

语义分类（v6 明确）：② 与 ③ 视觉刻意区分，反映生命周期不同——SystemNotice（②持久历史标记）compaction/branch 完成后永久留在消息流，虚拟列表内的 inline 行，用双侧分隔线（无 bg 无 shadow）记录「这里发生过什么」；瞬时浮层（③进行态/完成态指示）abs 定位读 vlistBottom 堆叠，出现又消失，用浮层卡片（bg-surface shadow-sm）。生命周期关系：压缩中（瞬时进行态）→ 完成后消失，由 SystemNotice（持久记录）取代其在消息流的位置，即「瞬时浮层完成 → SystemNotice 持久记录」。二者不可合并：瞬时浮层是「正在发生/刚发生」的临时指示，SystemNotice 是「曾经发生」的永久档案。
