§1

badge 三轴语义体系

一个扩展卡片同时携带三个独立维度：source（来源：user-installed / discovery）、mandatory（是否强制）、tier（强制分级：infrastructure / feature）。原版把三者都画成 accent-soft 同形 pill，三轴无视觉区分。v6 强制三轴各异形状——source 用 Pill（分类）、mandatory 用锁图标 + 字（状态）、tier 用 dot + monospace（弱化限定），呼应 design-system.md §5「Pill / Badge / Status Dot 强制区分」。

已安装 · user-installed 卡片（开关+升级+自动升级）

§6

卸载 · 两段式确认

卸载是破坏性操作，两段式确认是必要保护（非 modal 偷懒——product.md 反 modal-as-first-thought，但破坏性操作除外）。点卸载 → ConfirmDialog（variant=danger）：危险图标 + 标题（含扩展名）+ 描述（说明后果）+ 取消（ghost）/ 卸载（danger）。容器与按钮范式对齐 v6-spec-overlays.html §4 ConfirmDialog SSOT（bg-surface + border + shadow-2 + radius-lg 12px；取消 ghost / 确认 danger）。loading 态确认按钮显 spinner 防双击。mandatory / discovery 来源不进此流（无卸载按钮）。

确认 浏览器原生 confirm v6 ConfirmDialog variant=danger + 目标名 双击 无防护 v6 uninstalling 期 disabled
卸载 my-custom-tools？

该扩展将从扩展目录移除，其提供的工具在新会话不再可用。此操作不可撤销。

触发: 点卸载 → confirmTarget=name → dialog open
容器 SSOT: 对齐 overlays §4 ConfirmDialog · bg-surface + border(--border) + shadow-2 + radius-lg 12px + padding 24px · backdrop blur(4px) 0.8
图标: overlays cd-ico · 16px danger AlertTriangle（title-row 内联，取代独立大圆底块）· 与 overlays danger variant 同形
标题: 含扩展名（cd-target mono）· 明确操作对象
描述: 说后果（移除+新会话不可用+不可撤销）非笼统确认
取消按钮: .btn-ghost（overlays cd-actions 取消=ghost 范式 · 透明底 hover surface-hover）
确认按钮: .btn-danger（text-danger hover danger-soft）· 动词+对象「卸载」· 与 overlays danger confirm 同形
loading: uninstalling → 确认钮 disabled + spinner
不适用: mandatory（锁定）/ discovery（无卸载按钮）不进此流

§8

错误态 / 空态

两类边界：① 安装/升级失败——非静默吞，内联 danger 错误条说「原因 + 下一步」（design-system §9 文案语气）+ Toast 反馈成功态。② 空态——已安装列表为空时三要素：图标 + 一句说明 + 一个 Primary 入口（design-system §7），指向安装区而非裸「暂无数据」。

失败 console 静默 v6 内联 danger 错误条 + Toast 成功 空态 「暂无扩展」裸文 v6 图标+说明+入口三要素
升级失败 · 内联错误条 + actionError 文案
升级失败：网络超时 · 检查网络后重试，或开启「自动升级」由后台重试
已安装列表空态 · 图标 + 说明 + Primary 入口（default Button 指向安装区 §4/§5）
还没有安装任何扩展 从 npm 包名、本地目录或 Git URL 安装第一个扩展
错误条: border-top hairline · AlertCircle + danger 文案
错误文案: 「原因 + 下一步」（design-system §9）非裸错误码
成功 Toast: installedToast / uninstalledToast / upgradedToast
空态三要素: 图标（subtle）+ 说明 + Primary 入口（Button default 指向安装区 §4/§5）
