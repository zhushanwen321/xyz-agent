§1

badge 三轴语义体系

一个扩展卡片同时携带三个独立维度：source（来源：user-installed / discovery）、mandatory（是否强制）、tier（强制分级：infrastructure / feature）。原版把三者都画成 accent-soft 同形 pill，三轴无视觉区分。v6 强制三轴各异形状——source 用 Pill（分类）、mandatory 用锁图标 + 字（状态）、tier 用 dot + monospace（弱化限定），呼应 design-system.md §5「Pill / Badge / Status Dot 强制区分」。

§6

卸载 · 两段式确认

卸载是破坏性操作，两段式确认是必要保护（非 modal 偷懒——product.md 反 modal-as-first-thought，但破坏性操作除外）。点卸载 → ConfirmDialog（variant=danger）：危险图标 + 标题（含扩展名）+ 描述（说明后果）+ 取消（ghost）/ 卸载（danger）。容器与按钮范式对齐 v6-spec-overlays.html §4 ConfirmDialog SSOT（bg-surface + border + shadow-2 + radius-lg 12px；取消 ghost / 确认 danger）。loading 态确认按钮显 spinner 防双击。mandatory / discovery 来源不进此流（无卸载按钮）。

确认 浏览器原生 confirm v6 ConfirmDialog variant=danger + 目标名 双击 无防护 v6 uninstalling 期 disabled

§9

扫描目录管理（discovery.json · 项目 / 全局）

扩展、skill、agent 的扫描目录是同一类概念，都该支持项目维度和全局维度——参考资源页 LoadPaths 范式。但底层不是资源页的 projectPaths + globalPaths 双字段，而是 discovery.json（~/.xyz-agent/pi/agent/discovery.json）的三数组：extensionDirs / skillDirs / agentDirs，每个数组内部按路径性质自动归类（绝对路径 = 全局，相对路径 = 项目级），数组顺序即优先级（靠前覆盖靠后）。顶部 SegmentedTab 在三组间切换，每组内按「项目目录 / 全局目录」双分组呈现，行尾 ↑↓ 调优先级 + 移除；系统预设目录（PRESET_EXTENSION_DIRS）锁定在对应组顶部不可移不可关。

现 已安装扩展管理为主，无扫描目录入口 v6 新增扫描目录管理 section 三 tab extension / skill / agent 共享机制 双分组 项目目录 / 全局目录（scope pill 区分） 优先级 数组顺序即优先级（非项目 > 全局） 
// discovery.json（~/.xyz-agent/pi/agent/discovery.json）— SSOT：provider.ts DiscoveryConfig
interface DiscoveryConfig {
  version: 1
  extensionDirs: string[]   // extension 扫描目录（本 tab 默认呈现）
  skillDirs:     string[]   // skill 扫描目录
  agentDirs:     string[]   // agent 扫描目录
}
// 每个数组内部：绝对路径 = 全局（与 cwd 无关），相对路径 = 项目级（依赖 session cwd）
// 数组顺序 = 优先级：靠前覆盖靠后（同名资源取首个 enabled 目录的版本）
// preset 候选（PRESET_EXTENSION_DIRS）：~/.pi/agent/extensions（全局）/ .pi/extensions（项目）/ .xyz-agent/extensions（项目）
三类目录: extension / skill / agent 各自独立管理，共享同一套项目/全局 + 优先级机制
项目目录: 相对路径（.xyz-agent/extensions）· 仅当前项目生效（依赖 session cwd）
全局目录: 绝对路径（~/.pi/agent/extensions）· 与 cwd 无关 · 所有项目共享
优先级语义: 数组顺序即优先级 · 项目与全局混合在同一数组按顺序统一排序——不是「项目 > 全局」（这点与资源页不同）
自动归类: 添加时按路径性质判定：绝对路径 → 全局组，相对路径 → 项目组（expandHome 后 isAbsolute 判定）
与资源页差异: 资源页是 projectPaths + globalPaths 双字段且 project > global；本页是单数组混合、数组顺序即优先级——spec 在 anno 与 §9.2 显式标注此差异
