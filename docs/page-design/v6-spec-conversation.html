§5

Block · bash

bash 有两个来源，渲染不同，必须区分：① BashOutputBlock——composer 用 ! 前缀直接执行的 bash，独立系统消息，不可折叠，header 显完整命令 + exit 状态标签；② tool-bash——agent 调用的 bash 工具，嵌在 tool 块内（见 §6），可折叠，展开后用 border 容器渲染命令+输出。两类 v6 统一：去嵌套卡片视觉冗余，failed 中性化。

区分 BashOutputBlock（不可折叠）≠ tool-bash（可折叠） failed exit 标签中性化（非 danger 红框）
