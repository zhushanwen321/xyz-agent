蚀仪鱼化 · 六式。以选定方案 A 蚀仪（白仪错位 24°）为基底，从双鱼戏参考图中提炼三样灵魂——流尾、须、游势——用单线 stroke 克制地表达，做成一把加法梯：B1 燕尾（最克制）→ B2 流尾 → B3 燕尾·须 → B4 流尾·须（最接近参考图，仍无鳞无鳍）；另保留负空间双版 C1 醒 / C2 梦（一笔不添）。

从参考图提炼什么，舍弃什么

双鱼戏图动人之处在三处：流尾——尾巴不收于形内，顺着游势拖出长线；须——鱼首前缘一缕，是「鱼感」最强的一笔；游势——身体沿圆的切线游动，尾向与游向相反。参考图的「花」在鳞片、鱼鳍、水波与色彩——这些全部舍弃，只取三样灵魂，各用一两笔单线表达。

四个鱼化变体是一把加法梯：B1 燕尾只添两笔剪刀尾（最克制）；B2 把尾换成一笔长流尾，游势顿生；B3 在燕尾上给两鱼首各点一缕须——须是性价比最高的一笔，有须即是鱼；B4 流尾加须，最接近参考图的神，仍无鳞无鳍无色彩。游势的底色：四式的尾都顺着两鱼的自然尖梢（白尾左下 (41,102)、黑尾右上 (79,18)），流尾的拖曳方向沿圆的切线、与游向相反——尾在先，鱼在后，两鱼首尾相逐。

须的位置：鱼首前缘（白鱼鼻 (40,18)、黑鱼鼻 (80,102)，互为 180° 对位），只一缕，探出圆盘。浅底场景白须近隐（stage 如实展示），favicon 一律删须保尾——16px 下须会糊成噪点。

负空间双版（C1/C2）维持上轮结论一笔不添：负空间的主角是「缺」，尾与须都会把注意力拉回「鱼」。另：v4 蚀仪鱼眼已归位两枚鱼首（白鱼首 (50,39)、黑鱼首 (70,80)，经像素采样验证），六式统一。

鱼化四式 · 全盘版（任意底色自洽）

B1 蚀仪 · 燕尾 双鱼各一尾 · 最克制

只添两笔：顺着两条鱼各自的自然尖梢，各引一组对称剪刀尾——白尾左下 (41,102)，黑尾右上 (79,18)，180° 对位，双双探出圆盘。加法梯的第一级，鱼感点到即止。

设计逻辑
  • 尾在尖梢：阴阳鱼的尾本就在太极图的两个尖梢处——尾顺着尖梢长出来，是图形自身的延伸
  • 双鱼对位：两尾互为 180° 对位，与太极的中心对称同源
  • 加法梯第一级：只添两笔，是「太极」与「双鱼」之间最少的一步
  • favicon：双尾加粗到 3.5，16px 下依然可辨
B2 蚀仪 · 流尾 尾随游势 · 绵长一笔

把剪刀尾换成一笔长流尾：从尖梢拖出，沿圆的切线方向（鱼游动的反方向）拖曳——白尾沿底部弧线向右流，黑尾沿顶部弧线向左流，两尾 180° 对位。参考图里「游」的感觉，主要靠这一笔。

设计逻辑
  • 尾向 = 游向的反向：流尾沿圆的切线拖曳，尾在先、鱼在后——静态图形里读出「正在游」
  • 一笔流尾：比燕尾更绵长，比参考图的飘带尾克制——不带分叉、不带波浪
  • 首尾相逐：白尾流向黑鱼首一侧，黑尾流向白鱼首一侧，两鱼相逐的环形叙事闭合
  • favicon：流尾加粗到 3.5；16px 下流尾辨识度优于燕尾（线长、走向明确）
B3 蚀仪 · 燕尾·须 一须点首 · 有须即鱼

燕尾之上，给两枚鱼首前缘各点一缕须——白须自白鱼鼻 (40,18) 探出，黑须自黑鱼鼻 (80,102) 探出，180° 对位。须是性价比最高的一笔：有须即是鱼，无须仍是图。

设计逻辑
  • 须在鱼鼻：须点在鱼首前缘（白鼻 (40,18)、黑鼻 (80,102)），不是鱼身两侧——位置错了就像虫子
  • 一缕即止：参考图的须常画两三缕，这里只一缕——第二缕开始滑向「锦鲤插画」
  • 须细于尾：须 stroke 2.5、尾 stroke 3——须是点缀，尾是资产，层级不能倒
  • favicon 删须保尾：16px 下须糊成噪点，须只属于 ≥64px 的场景
B4 蚀仪 · 流尾·须 最接近参考图 · 仍无鳞鳍

加法梯的最后一级：流尾 + 须。流尾给游势，须给鱼感，两者齐备后双鱼戏的神就齐了——但仍然无鳞、无鳍、无水波、无色彩，与参考图的花哨保持最后一道距离。

设计逻辑
  • 神似参考图的底线：流尾 + 须是「双鱼戏」神似的最小集合——再减一笔鱼感衰减，再加一笔（鳞/鳍/波）就开始花哨
  • 尾与须的呼应：尾向后流、须向前探，鱼首鱼尾各有交代，身体的「中段留白」反而成了克制
  • 层级不变：尾 3 / 须 2.5，favicon 删须保流尾
  • 风险：四式里最接近插画的一式——若嫌「太鱼」，回退 B2；若嫌「不够鱼」，这是上限，不再加

负空间双版 · 一笔不添（锁底色）

C1 负空间 · 醒 白底无框 · 黑鱼独游

白底上，白色半仪不画任何轮廓，溶进背景——画面只剩一条黑鱼（错位 24° 的半仪，一笔不添）、黑鱼首上的白点，以及浮在空白处的一枚黑点：消失的白鱼只留下它的眼睛。

设计逻辑
  • 白鱼去哪了：观者会下意识补全白鱼的轮廓——负空间的参与感，比画出来的圆更有余味
  • 浮眼：黑点孤零零浮在空白处，是全图最「玄」的一笔——鱼的躯体没了，注视还在
  • 一笔不添：负空间的主角是「缺」——尾与须都会把注意力拉回「鱼」，故保持纯错位太极
  • 代价：锁白/浅底。深底下黑鱼隐形（对照 stage 如实展示），深底场景请用 C2
C2 负空间 · 梦 黑底无框 · 白鱼独游

黑底上的镜像版：黑色半仪溶进背景，只剩一条白鱼（与 B 式同向的纯错位半仪）、白鱼首上的黑点，以及浮在暗处的一枚白点。白鱼更像「梦中那条」——看得见轮廓，没有实体依托。

设计逻辑
  • 与 C1 互为醒梦：白底黑鱼是「醒时的太极」，黑底白鱼是「梦中的太极」——同一形体的两种在场方式
  • 浮眼在暗处：白点浮在黑底上像星——黑鱼消失了，但它的注视与夜空同色
  • 中灰底仍可用：白鱼对中灰有足够对比（对照 stage 验证），适应性略优于 C1
  • 代价：锁深底。白底下白鱼隐形（对照 stage 如实展示），浅色场景请用 C1 或 B 式

六式速览与使用建议

式一句话底色适应小尺寸气质
B1 燕尾尖梢双剪尾，鱼感点到即止任意底色自洽佳（尾加粗）正局、静
B2 流尾一笔长流尾，尾随游势而出任意底色自洽佳（流尾走向明确）动、绵长
B3 燕尾·须燕尾 + 鱼鼻各一缕须任意（浅底白须近隐）删须保尾俏、一点生气
B4 流尾·须流尾 + 须，神似参考图的底线任意（浅底白须近隐）删须保流尾游、逍遥
C1 醒白底上白鱼无形，黑鱼独游锁白/浅底佳极简、文人
C2 梦黑底上黑鱼无形，白鱼独游锁深底（中灰可用）佳玄、夜空感

选型建议：主标从 B 式中选——求最克制选 B1，求游势选 B2（推荐：流尾是参考图灵魂的最大单笔收益），求「一看就是双鱼」选 B4；B3 居中。C1/C2 按底色专用：官网浅色页/文档用 C1，深色启动页/hero 用 C2，跨底色通用场景回退 B 式（自带黑白盘面，不需要关心底色）。六式共用同一错位角、同一鱼眼位、同一对尖梢——是同一资产的六种出场方式，而非六个 logo。

尾与须是本轮的全部加法，位置都有出处：尾顺两鱼的自然尖梢（白左下、黑右上），须点两鱼的前缘鼻位（白 (40,18)、黑 (80,102)），皆 180° 对位，与太极的中心对称同源。选定后下一步：矢量化精修（流尾贝塞尔的张力、须的弧度、错位角的微调），以及动效版——流尾与须天然适合做点水摆尾的微动效。
