太极 · TAIJI — LOGO 概念探索 Kimi v5

蚀仪深化 · 三式。以 v4 选定方案 A 蚀仪（白仪错位 24°）为基底：A1 添鳍——给白鱼添一点点鱼的感觉（一尾一鳍，仅此而已）；A2 负空间·醒——白底上白色半仪不画边框，只剩黑鱼与两枚眼；A3 负空间·梦——黑底上黑色半仪不画边框，只剩白鱼与两枚眼。

添鳍的克制 与 负空间的代价

阴阳「鱼」本就是太极图的俗名，但标准太极从不画鱼——鱼感全靠观者对逗号形的联想。A1 只添两笔：尾尖一枚小叉鳍（出盘，鱼要游走）+鱼身一道小鳍线。不画鳞、不画鳃、不画须——再多一笔就从「太极」滑向「锦鲤」。

负空间版把「太极自带黑白盘面」的特性反过来用：与底色同色的那一半不画轮廓，溶进背景——白底上白鱼消失了，只剩黑鱼孤零零地游，以及两枚眼：一枚在黑鱼头上（白点），一枚浮在空白处（黑点）——消失的鱼只留下它的眼睛，这是负空间版最耐看的细节。

代价要明说：负空间版锁定底色（A2 只能白/浅底，A3 只能深底），跨底色场景回退 A1（自带盘面，任意底色自洽）。每张卡片的对照 stage 如实展示了失效场景。

另：本轮修正了 v4 蚀仪的鱼眼位置——原稿两枚眼未落在鱼首上（各自沉入同色区域而隐形），A1/A2/A3 及 v4 文件均已归位（白鱼首 (50,39)、黑鱼首 (70,80)，经像素采样验证）。

A1 蚀仪 · 添鳍 一尾一鳍 · 鱼将出盘

蚀仪原样，只添两笔：白鱼尾尖一枚小叉鳍——探出圆盘边界，鱼要游出太极；鱼身中部一道小鳍线（黑、50% 淡）。鱼眼归位到两枚鱼首。黑盘、错位、灰环全部照旧。

设计逻辑
  • 只添两笔：尾鳍 + 身鳍，鱼感到此为止——再多一笔就变锦鲤
  • 尾鳍出盘：尾尖探出圆盘边界，是「游」也是「逍遥」——鱼不完全属于这个圆
  • 鱼眼归位：黑点在白鱼首 (50,39)、白点在黑鱼首 (70,80)，修正 v4 鱼眼沉入同色区域隐形的问题
  • favicon：删身鳍保尾鳍——尾鳍是资产，16px 下依然可辨
A2 负空间 · 醒 白底无框 · 黑鱼独游

白底上，白色半仪不画任何轮廓，溶进背景——画面只剩一条黑鱼（错位 24° 的半仪 + 尾鳍 + 白鳍线）、黑鱼首上的白点，以及浮在空白处的一枚黑点：消失的白鱼只留下它的眼睛。

设计逻辑
  • 白鱼去哪了：观者会下意识补全白鱼的轮廓——负空间的参与感，比画出来的圆更有余味
  • 浮眼：黑点孤零零浮在空白处，是全图最「玄」的一笔——鱼的躯体没了，注视还在
  • 黑鱼尾朝左下：与 A1 的白鱼尾成 180° 对位，两版并置时鱼尾各指一方
  • 代价：锁白/浅底。深底下黑鱼隐形（对照 stage 如实展示），深底场景请用 A3
A3 负空间 · 梦 黑底无框 · 白鱼独游

黑底上的镜像版：黑色半仪溶进背景，只剩一条白鱼（与 A1 同向、尾鳍出盘）、白鱼首上的黑点，以及浮在暗处的一枚白点。白鱼更像「梦中那条」——看得见轮廓，没有实体依托。

设计逻辑
  • 与 A2 互为醒梦：白底黑鱼是「醒时的太极」，黑底白鱼是「梦中的太极」——同一形体的两种在场方式
  • 浮眼在暗处：白点浮在黑底上像星——黑鱼消失了，但它的注视与夜空同色
  • 中灰底仍可用：白鱼对中灰有足够对比（对照 stage 验证），适应性略优于 A2
  • 代价：锁深底。白底下白鱼隐形（对照 stage 如实展示），浅色场景请用 A2 或 A1

三式速览与使用建议

式一句话底色适应小尺寸气质
A1 添鳍蚀仪 + 一尾一鳍，鱼将出盘任意底色自洽佳（删身鳍）正局带一点生气
A2 醒白底上白鱼无形，黑鱼独游锁白/浅底佳极简、文人
A3 梦黑底上黑鱼无形，白鱼独游锁深底（中灰可用）佳玄、夜空感

使用组合：A1 为主标（App icon、favicon、任意底色的通用场景——自带黑白盘面，唯一不需要关心底色的版本）；A2 用于白底场景（官网浅色页、文档、名片、浅色启动屏）；A3 用于深底场景（深色启动页、官网 hero、周边）。三式共用同一错位角与同一尾鳍，是同一资产的三种出场方式而非三个 logo。

尾鳍是本轮唯一的加法，也是这版logo区别于一切「太极变体」的资产点——建议在所有场景保留（favicon 亦不删）。鱼眼已归位鱼首。选定后下一步：矢量化精修（尾鳍曲线与错位角的微调、鱼首与眼的同心度），以及动效版（鱼尾摆动 / 蚀的推移 / 浮眼明灭）。
