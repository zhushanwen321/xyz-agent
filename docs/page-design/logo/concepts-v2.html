逍遥 FreeWise — 鲲鹏 × 道家留白 探索 v2

v1 的鲲鹏画成了一团实心封闭轮廓，违背了道家"计白当黑"。v2 贯彻：实形（翼）只占 30%，留白（天空/光/鹏形）才是主角。每案用不同留白手法。

道家思想 → LOGO 设计原则（本次 v2 的根基）
计白当黑：留白与实笔同等重要，真正的逍遥在"没画的部分"
虚实相生：画的是翼（实），藏的是鹏/光/道（虚）
大象无形：越抽象越近道，不画具象鸟，只画翼之"势"
气韵流动：翼是"气"的聚合，不是僵硬几何
鲲鹏记忆点 = 翼：「其翼若垂天之云」，翼是自由的直接视觉
向上 = 逍遥方向：「抟摇直上九万里」，张力永远朝上
方案 1 垂天之翼 极简双翼 · 留白即天空 · 最克制

「其翼若垂天之云」——只画两片锐利向上的翼（实），翼之间大片留白即天空（虚）。 翼是"框"，天空才是内容。翼上方一抹光点=鹏背负青天。实形占比 <25%，最大化留白。 设计手法：两笔翼的弧线托举起整片空间，留白呼吸感最强。

留白 = 天空
留白手法：减法留白——只画必要两笔，其余全空。
  • 实形占比 < 25%：两片翼 + 一光点，是所有方案里最克制的
  • 道家对应：「少则得，多则惑」——翼越简，天空（留白）越显，逍遥感越强
  • 向上的张力：翼上缘锐利上凸，像双手托举，光点在上方=鹏背负青天
  • 缩放最强：favicon 退化成「人字形+金点」，识别度依然高
  • 风险：双翼形态较常见，需靠光点 + 翼的锐利弧度做出独特
方案 2 负空间藏鹏 正负反转 · 虚实相生 · 最道家

「虚实相生」——画的是两片朝内弯曲的翼弧（实），翼围出的中央留白，自然形成一只展翅鹏的剪影（虚）。 看实形是抽象双弧，看虚形是一只鸟。真正的鹏从未被画出，却藏在留白里。这是道家"无状之状、无象之象"的视觉化。

留白手法：负空间藏形——实形（翼）围出的虚形（鹏）才是主体。
  • 道家对应：「无状之状，无象之象」——鹏从未被画出，却存在于留白。最契合道家
  • 双层阅读：第一眼看是抽象双弧（现代感），细看发现藏着一只展翅鹏（惊喜）
  • 双翼不对称配色：左蓝右紫=鲲（水/阴）与鹏（天/阳）的二元，阴阳调和
  • 道核金点：鹏形正中的金点是「道生一」的"一"，是整形的能量中心
  • 风险：负空间鹏形需要观者"发现"，辨识有门槛；16px 下负空间易糊
方案 3 太极化翼 S 脊柱分阴阳 · 鲲鹏统一 · 流动气韵

「万物负阴而抱阳，冲气以为和」——一条 S 形脊柱（太极的分界）把空间分成两片翼：左翼冷蓝（鲲/水/阴）， 右翼淡蓝紫（鹏/天/阳）。两片翼本是同一个"翼"的两面，由 S 曲线分隔又统一。不是封闭的太极圆，而是开放的展翅——太极是理，翼是形。

留白手法：分而不离——S 脊既是分界也是连接，两翼互为留白。
  • 道家对应：太极阴阳 + 展翅。把"太极"从封闭圆解放成开放翼形，理（太极）与形（翼）合一
  • 鲲鹏统一：左翼=鲲（深蓝/水/阴），右翼=鹏（紫/天/阳），同一翼的两面=鲲鹏本一体
  • S 脊柱=冲气：分隔阴阳的那条白线是"冲气以为和"，是动态的、可流动的（loading 动画）
  • 阴阳两点：呼应太极鱼的"目"，阴中有阳（蓝翼里藏紫点）、阳中有阴
  • 风险：双翼+中线结构信息量较大，需保证整体仍轻盈
方案 4 飞白一笔 书法笔触 · 飞白留白 · 最东方

「大巧若拙」——像草书一笔扫出的翼，笔触本身带"飞白"（书法中笔枯露白的技法）。 飞白就是书法里的留白——墨断意连，实中有虚。一笔从左下扫到右上分叉成双翼尖，气韵贯通。 最东方的表达：逍遥=游=行云流水般的笔意。科技感由渐变色和锐利收锋提供。

留白手法：飞白露白——笔触内部的断白就是留白，实中有虚。
  • 道家对应：「大巧若拙」——看似随意的草书一笔，内有气韵秩序。逍遥=游，笔意即游意
  • 飞白=书法留白：两道断笔（深色叠加）模拟笔枯露白，是东方特有的留白技法
  • 渐变=气韵：蓝→金渐变是气的流动，收锋金色=鹏翼触天光
  • 书写动画天然：loading 可做"一笔写成"的动画，最有东方韵味
  • 风险：可能偏"国风"而弱化科技感；飞白在 16px 下需去掉（见 favicon）
