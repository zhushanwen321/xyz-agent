蝶即两仪 · 五式。整个 LOGO 就是一只蝶：翅膀本身长成太极两仪，一实一虚。没有外圆、没有容器、没有 S 线描边——太极只以「神」存在：S 形的分界、互藏的异色点、首尾相逐的动势。五式从「最太极」到「最蝶」排开：A 翼仪蝶身骑在太极 S 界上 → B 锁翼四翅斜向互锁成仪 → C 侧影侧视双翅前实后虚 → D 逐翅两枚涡纹相逐成蝶 → E 散翼实翅与虚化散尘的虚翅。

「神似而非形似」的三个支点

太极的「形」是圆 + S + 两点，全画出来就是太极不是蝶。它的「神」是三样东西：曲线分界（两半不用直线分，用互相咬合的曲线分）、互藏（实的一半里藏一点虚，虚的一半里藏一点实）、追逐（两半不是静止对称，而是首尾相衔、随时可以转起来）。五式都不画圆，只用这三招让翅膀「自己长成两仪」。

「虚」的语义落在梦蝶题眼上：实的那半是醒时的周，虚线的那半是梦中的蝶——看得见、摸不着，但结构完整。这不是装饰手法，是「周与蝶必有分矣」的直接成像。

色彩语义不变：蓝 = 实 = 醒，紫 = 虚 = 梦。五式全部无文字、无外框，favicon 等效稿照常做 16px 压力测试。

A 翼仪 蝶身骑仪 · 最太极

两枚翅膀直接就是太极的两条鱼：左翼实心（蓝）、右翼虚线（紫），中间 S 形咬合线上骑着蝶身与触角。轮廓不画外圆——圆由两枚翼形自己围出来，你看得到它，但它不存在。

设计逻辑
  • 翼即鱼：太极鱼形天然像一瓣翅膀——饱满的肥头是翅面，收窄的鱼尾是翅根。这是太极与蝶形最近的一次重合
  • 不画的圆：两条鱼围出的圆形轮廓是「虚的圆」——观者自己脑补，恰合「无之以为用」
  • 蝶身骑界：身体骑在 S 分界上，触角探出圆外——蝶不属于任何一仪，它是「分」本身
  • 风险：太极感最强但也最容易被读成「太极变体」而非蝶，蝶的识别靠触角和身体撑
B 锁翼 四翅互锁 · 蝶形最正

标准前视蝶，但虚实不按左右分，按对角互锁分：左上翅 + 右下翅为实（蓝），右上翅 + 左下翅为虚（紫虚线）——太极阴阳鱼对角相咬的动势直接搬进四翅。实翅上一点空环（实中虚），虚翅上一点实心（虚中实）。

设计逻辑
  • 对角互锁：太极的两仪从不是左右静对，而是斜向相咬——对角分虚实，四翅立刻有了「正在流转」的动势
  • 蝶形最正：五式中最标准的前视蝶剪影，不需要解释就知道是蝶；两仪结构藏在填色逻辑里，第二层才被读出——正是「神似」
  • 异色点互藏：实翅藏空环、虚翅藏实点，阴阳互根落在翅面上
  • favicon：小尺寸删点保形，对角蓝紫对比在 16px 下依然可辨
C 侧影 侧视双翅 · 前实后虚

侧视角度：前翅实心（蓝，醒时的一切），后翅虚线（紫，梦的残影），蝶身一笔弯曲的书法线，两点触角。两翅一前一后、一实一虚——同一只蝶的两个时态叠在一帧里，像曝光两次的照片。

设计逻辑
  • 前后即虚实：侧视让两翅天然分出前后——前翅是「此刻」，后翅是「方才」，物化的时间感不需要散点就有了
  • 书法一笔：蝶身是单条弯曲线，不画节肢不画鳞粉，文人气最重的一式
  • 两仪在哪里：不借太极的形——实与虚的并置本身就是两仪。五式中「太极形」最弱、「虚实神」最纯
  • 风险：不对称构图有固定朝向；侧视蝶识别依赖轮廓功力，favicon 已删触角加厚线条
D 逐翅 双涡相逐 · 最抽象

蝶被抽象成两枚相逐的涡纹（先秦双旋涡与太极鱼共用的那个母题）：一实（蓝）一虚（紫虚线），沿对角线首尾相衔，中央一粒白点是蝶身也是两仪的种子。既是展翅的一瞬，也是旋转的太极。

设计逻辑
  • 涡即翅：双旋涡纹是「蝶」与「太极」在考古层的共同祖先——两枚涡纹相逐，看成蝶翅的扇动或两仪的流转都成立
  • 种子居中：中央白点一物三读——蝶身 / 两仪未分之「一」 / 万物之种
  • 最现代：几何感最强，适合偏科技/工具的品牌气质；「蝶」需要半秒才看出来，但这半秒正是记忆点
  • favicon：三图元（双涡 + 一点），16px 下最干净的方案之一
E 散翼 左翼为实 · 右翼化尘

前视蝶，左翅完整实心（蓝，醒），右翅只剩虚线轮廓、翅尖散作微尘（紫，梦正在醒来）。蝶身在中间，一半属于实、一半属于虚——「不知周之梦为胡蝶与，胡蝶之梦为周与」的那个「不知」，画在一只蝶身上。

设计逻辑
  • 一蝶两态：左翅是「形」，右翅是「影」，尘是「化」——物化三段论收敛进单只蝶，不借助外圆
  • 叙事最强：五式中唯一有「正在发生」的时间感——右翼正在散，观者会下意识替它补完
  • 两仪的另一种读法：左右不是对称的两半，而是同一物的两种存在方式——比左右均分更接近「物化」本意
  • 风险：方向性构图；散点在极小尺寸删减为两点（favicon 稿已处理）

五式速览与挑选建议

式一句话蝶识别太极神似小尺寸气质
A 翼仪翼即双鱼，蝶身骑 S 界中（靠身与触角）最高良道法、徽章感
B 锁翼四翅对角互锁成仪最高高（填色逻辑层）佳均衡、现代
C 侧影侧视双翅，前实后虚高弱（虚实并置而已）中文人、书法
D 逐翅双涡相逐，种子居中弱（需半秒）高最佳抽象、科技
E 散翼左翅为实，右翅化尘高中良（删点后）诗意、叙事

主推 B 锁翼：蝶形最完整（一眼是蝶），两仪不靠轮廓靠填色逻辑藏在第二层（再看是太极）——正是「神似而非形似」的题解；上下左右都对称，小尺寸与单色场景都稳。A 翼仪次之：太极的神最足、最「道」，适合愿意牺牲一点蝶识别度换哲学浓度的定位。E 散翼叙事最动人，若想让 logo 自己会讲故事就选它，并可延伸做 loading 动效（右翼散了又聚）。C 侧影最文雅，适合偏人文的品牌调性。D 逐翅最抽象现代，favicon 性能最好，可作 B 的抽象变体配套使用。
