梦蝶两仪 · 五式。本轮以梦蝶为体（庄子物化）、两仪为骨（太极的圆与对称结构）、虚实为神（实形与虚形互藏）。五式共用同一只蝴蝶几何与同一个圆，区别在于蝶与太极的关系不同：A 双蝶仪双蝶相逐即成两仪 → B 蝶目蝶作太极之眼 → C 物化蝶散为尘穿过虚侧 → D 蝶影水上实蝶水下虚影 → E 简蝶一实一虚双翅极简。

为什么梦蝶 × 两仪 × 虚实是成立的组合

庄生梦蝶的核心是「物化」——周与蝶「必有分矣」，却又互化不分彼此。这与太极两仪的结构天然同构：两仪也是「有分而相生」，阴中藏阳、阳中藏阴。蝶与周，恰好可以坐上两仪的位置——一实一虚，互为对方的「鱼眼」。虚不再只是装饰手法，而是叙事本身：虚的那只蝶，就是梦里的那只。

手法规矩沿用上一轮：每式只用一种「虚」的手法（虚线 / 散点 / 镜像），蝴蝶保持同一只、不画花纹触角，避免「水墨蝴蝶画」的成品感。五式全部不带文字。

小尺寸是梦蝶方案的老问题（翅形在 16px 下容易糊），所以每式都附 favicon 等效稿做压力测试：E 式是为此专门设计的极简版，A/D 靠对称骨架硬扛，C 的散点在小尺寸做了删减。

A 双蝶仪 双蝶相逐 · 首尾成仪

太极的两条鱼换成两只蝶：实蝶（蓝）与虚蝶（紫，虚线描边）沿圆周首尾相逐，追逐的动势本身就是 S 形的两仪流转。实蝶前方一颗紫点、虚蝶前方一颗蓝点——互藏其根，各含对方之性。外圆右实左虚。

设计逻辑
  • 双蝶即双鱼：太极最经典的双鱼互逐结构，鱼换成蝶——识别度最高的一种融合，动势最强
  • 互逐即物化：实蝶追虚蝶、虚蝶追实蝶，「周之梦为蝶与？蝶之梦为周与？」的循环可视化
  • 异色点：各含对方一颗种子，阴阳互根的极简表达
  • 风险：两只蝶 + 两点 + 双弧，元素偏多，favicon 稿已删点保形
B 蝶目 蝶作鱼眼 · 虚水之桥

保留你选定的虚水骨架（右实弧 + 左虚弧 + S 水笔），把两枚鱼眼换成两只小蝶：上眼是实蝶（白），下眼是虚蝶（紫虚线）。水身之内，藏梦为目。这是从 v2 虚水过渡到梦蝶最平滑的一式。

设计逻辑
  • 鱼眼即蝶：太极「阴中有阳」的那两点，恰是两只蝶——梦藏在水的身体里，体量小但位置极关键
  • 与虚水同源：若你对 v2 虚水仍有留恋，这式是它的直接进化，骨架不变、只换睛
  • favicon 妥协：小尺寸虚线蝶糊，改为实心紫蝶（虚实靠上下两色表达）
  • 风险：蝶在 80px 主标里只有 ~19px 翅展，「蝶」的识别弱于其他式，更像「太极+翼形目」
C 物化 蝶散为尘 · 穿实入虚

圆分两侧：左侧实弧（金，蝶所从来）、右侧虚弧（紫，蝶所去往）。一只金蝶由左向右飞，身后（或说前方）先化作一只虚线残影，再散作一串微尘没入虚侧。蝶 → 影 → 尘，物化的三个时态画在同一帧里。

设计逻辑
  • 一帧三时态：实蝶（昔之周）→ 虚影（化之中）→ 微尘（今之蝶散），「物化」的过程哲学直接成像
  • 实弧生蝶，虚弧纳尘：外圆的虚实两侧各有职司，不是装饰
  • 金色蝶：五式中唯一用暖金的主体——「周」的人间温度，与冷色虚侧拉开生死/醒梦温差
  • 风险：方向性构图（左→右），旋转/镜像场景不适用；散点在极小尺寸仍需删减（favicon 已只留两点）
D 蝶影 水上实蝶 · 水下虚影

圆即水面：上半圆实线、下半圆虚线，中间一道横 S 水线是水的表面。水上一只实蝶（蓝），水下是它的倒影（紫虚线，镜像）。蝶与影隔着水面相望——周与蝶，究竟哪边是倒影？太极、水、虚、蝶四个概念在这式里各有其位，无一多余。

设计逻辑
  • 四概念各就其位：圆 = 太极，横 S = 水，虚线 = 虚，蝶 = 梦蝶——没有堆砌，每个元素只干一件事
  • 影即虚：倒影天然是「在而非实」的东西，用虚线画倒影，虚实概念与日常经验同构，不需要解释
  • 上下对称骨架：垂直镜像构图比斜向更稳，小尺寸识别五式中最好
  • 叙事余味：「哪边是实蝶哪边是影」没有答案——正如周与蝶不知谁梦谁
E 简蝶 一实一虚 · 双翅极简

删到不能再删：圆（右实左虚）内一只蝶，右翅实心（蓝）、左翅虚线（紫）、蝶身一线（白）。两仪收敛进蝶的身体里——一只蝶自己就是虚实相生。为 favicon / 16px 场景专门设计，也可作其他式的子标。

五式速览与挑选建议

式一句话太极识别小尺寸叙事性气质
A 双蝶仪双蝶相逐即成两仪最高良（删点后）中（追逐循环）灵动、有生气
B 蝶目虚水骨架，蝶作鱼眼高良（favicon 改实心）弱（点睛式）克制、稳妥
C 物化蝶 → 影 → 尘，一帧三时态中中（散点需删减）最高诗意、有故事
D 蝶影水上实蝶、水下虚影高最佳（上下对称）高（谁梦谁）静观、禅意
E 简蝶一蝶自身即两仪中最佳（三图元）中现代、徽章感

主推 D 蝶影：太极（圆）、水（横 S）、虚（虚线倒影）、蝶四个概念各就其位，上下镜像的对称骨架在小尺寸最稳，「蝶与影孰真」的悬念正是梦蝶题眼。A 双蝶仪次之——动感与太极识别最强，适合偏「逍遥游」飞扬气质的定位。E 简蝶建议无论选哪式都保留，作为 favicon / 16px 场景的配套子标。C 物化叙事最动人，适合做 loading 动效（蝶散为尘循环）与品牌故事页，作静态主标略挑场景。B 蝶目是虚水方案的平滑过渡，若对 v2 仍有留恋可取此式。

配色均沿用 design tokens（蓝 #4f8ef7 / 紫 #a78bfa / 金 #b08a3e，浅色底用 #2563eb / #7c3aed）；全部方案不含文字，蝴蝶为同一几何（defs 共享），选定后可做矢量化精修（锚点优化、光学补偿、网格对齐）。
