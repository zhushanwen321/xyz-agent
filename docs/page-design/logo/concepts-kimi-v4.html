太极 · TAIJI — LOGO 概念探索 Kimi v4

太极本色 · 六式。APP 定名「太极」，LOGO 以太极两仪图为本体，黑白为主基调，层次全部来自灰阶与透明度（#0f1013 墨 / #3f4148 沉 / #6b7280 灰 / #b9bcc4 淡 / #f5f6f8 白）。规矩不变：每式只用一种变形手法，不完全复刻太极图——A 蚀仪错位 → B 墨仪笔触 → C 层仪等高线 → D 旋仪螺线 → E 叠仪重叠共生 → F 弦仪光栅。

不照抄太极，但一眼是太极的六种手法

太极图的识别依赖三个特征：圆分两仪、S 咬合、互藏两眼。复刻全占等于用公共符号做 logo，没有资产性。六式的策略是「保留两个半特征，动半个」——错位、笔触、层叠、螺线、重叠、光栅各动一处，观者立刻认出太极，又说不出哪里不一样，那一处就是品牌自己的东西。

黑白主基调的好处：太极图自带黑白双色的完整盘面，在任何底色上都自洽（深底、浅底、中灰底通吃），这是彩色 logo 做不到的。「更多颜色层次」不加彩色，用灰阶与透明度做——墨分五色，本来就是道家的色彩观。

每式五档验证：深底主标 / App icon / favicon 16px 等效 / 浅色底 / 中灰底（黑白logo的终极压力测试）。

A 蚀仪 白仪错位 · 如月之蚀

黑盘为体，白色半仪旋转 24° 错位嵌入——太极还是那个太极，但两仪不再工整对位，像日蚀月蚀中错动的光影。双眼随错位偏移，外圈一圈极淡的灰环收边。最简单的一种变形，识别度几乎无损。

设计逻辑
  • 只动一个参数：白仪旋转 24°，其余全部照旧——改动最小、资产性最强，错位角就是品牌的「那一度」
  • 蚀的意象：黑白交错如日月之蚀，静中藏动；「太极」名与「蚀」形同属天象
  • 工程最稳：黑白自带完整盘面，深底/浅底/中灰底/任意照片底全部自洽，App icon 场景最立得住
  • 风险：变形克制，个性也最含蓄——是「正局」不是「奇局」
B 墨仪 飞白入纸 · 墨分三色

太极照旧，但它是「写」出来的：白仪带一层淡墨晕染（22% 透明度叠影），外圈不是闭合圆而是两段飞白笔触——浓的一笔 85%，枯的一笔 30%，写到一半墨尽了。层次全靠墨的浓淡，不加一色。

设计逻辑
  • 墨分三色：浓（白仪 100%）、淡（晕染 20%）、枯（飞白 30%）——「更多颜色层次」用墨的逻辑解决，不用彩色
  • 写到一半墨尽了：外圈不闭合，枯笔收尾——「大成若缺」落在笔画上
  • 浅色底换墨：白底上白墨不可见，改为黑墨书写（同一手法，反向执行）
  • 风险：飞白与晕染在小尺寸糊，favicon 稿已删枯笔保形；书法感需要载体气质配合
C 层仪 鱼形等高线 · 四层灰阶

太极只剩线：半仪轮廓按 1 / 0.7 / 0.42 三级嵌套，如等高线、如水波年轮，白 → 淡灰 → 中灰层层退去；对侧半仪只留一圈沉灰轮廓暗示存在。圆心一粒白点——万层之末，复归于一。

设计逻辑
  • 层即是层次：「更多颜色层次」直接字面化——同一鱼形三层嵌套、四级灰阶，像地形图也像声波
  • 虚的那半只剩一圈：对侧半仪用沉灰暗示，两仪的虚实对比换了一种说法
  • 中心白点：层层收敛后的「一」，无极而太极的那个起点
  • 风险：纯线稿在 16px 只能留两层（favicon 已减层）；气质偏理性建筑感，温度靠使用场景补
D 旋仪 S 入涡心 · 两眼成旋

太极转起来了：S 分界线不再止于圆心，而是继续卷入两侧眼位，收成两枚涡旋——一白一灰两条螺线臂互卷，外圈淡环收边。静太极变成动太极，「流转」从隐喻变成形状。

设计逻辑
  • S 不止于中点：标准太极的 S 到圆心就停了——让它继续卷进眼位，两仪立刻「转」起来
  • 涡即眼：两枚涡旋取代两枚圆眼，互藏的概念升级为互卷
  • 双灰阶螺臂：白臂主旋、灰臂副旋，层次最少但动势最强的一式
  • 风险：螺线末梢在 16px 糊，favicon 已截短为两段弧；动势强意味着静态场合略显「转不停」
E 叠仪 两仪相生 · 重叠成灰

两枚小太极（一枚正向、一枚旋转 180°）以 62% 透明度交叠，重合的透镜区自然调出一连串中间灰——黑白相交之处，灰自己长出来。「太极生两仪」变成「两仪生万象」：层次不是画上去的，是生出来的。

设计逻辑
  • 灰是生出来的：62% 透明度交叠，重合区自动出现黑→深灰→中灰→浅灰→白的连续谱——「两仪生万象」的色彩版
  • 正反倒置：两枚太极一正一反，如器与影、体与用
  • 最富层次：六式中灰阶最丰富的一式，完全契合「黑白主调 + 更多层次」的要求
  • 风险：双盘构图横向偏宽，方形 icon 里上下留白多；透明度叠加在部分低色深屏上可能出色带
F 弦仪 半仪光栅 · 渐隐成虚

右半仪是实心黑，左半仪不由色块构成——十条渐淡的横弦裁出半仪的轮廓，从 95% 白一路衰减到 13%，像信号渐弱、像琴弦、像水面将平的波纹。实的一半是「有」，弦的一半是「有之将无」。

设计逻辑
  • 弦的三种读法：琴弦（音）、波纹（水）、扫描线（信号）——传统符号与现代媒介感各占一半
  • 渐淡即虚实：十条弦的透明度梯度就是灰阶层次，虚的那半「正在消失」，比虚线更虚
  • 黑半守拙：实心黑仪纹丝不动，衬得弦仪更轻——「有之以为利，无之以为用」
  • 风险：细线在 16px 收成五根粗弦（favicon 稿已处理）；印刷小尺寸需专色灰版

六式速览与挑选建议

式一句话太极识别灰阶层次小尺寸气质
A 蚀仪白仪错位 24°，如月之蚀最高两层 + 灰环最佳正局、天象
B 墨仪飞白书写，墨分浓淡高浓/淡/枯三层良（删枯笔）书道、东方
C 层仪鱼形等高线，复归一点中四级灰阶中（减层）理性、建筑
D 旋仪S 卷入涡心，两眼成旋中高白灰双臂中（截短）动势、流转
E 叠仪两仪交叠，灰自己长出来高（双盘）最富（连续谱）良哲思、共生
F 弦仪半仪化作十条渐淡的弦高十级渐变良（收五弦）现代、信号

主推 A 蚀仪：变形最小、太极识别最高，黑白自带盘面在任何底色自洽，App icon 场景最稳——「太极」二字配得上一个正局logo。E 叠仪最贴合「更多颜色层次」的要求：灰不是画的，是两仪相交自己生出来的，哲学与形式咬得最紧，作品牌主视觉极有故事。B 墨仪东方气质最浓，适合想让「太极」带书卷气的定位。F 弦仪最现代，若产品气质偏科技工具可直上。C 层仪、D 旋仪是风格边界的探索，适合作为动态 logo 或周边视觉的母题。
