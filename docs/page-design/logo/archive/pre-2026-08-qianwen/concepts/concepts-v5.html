第 1 组 · 动静相生

「静水映月、上善若水、御风而行。」 — 三境合一：水与风

主题：水（液态的逍遥）+ 风（气态的逍遥）。用 4 种调性（水墨 / 几何 / 印章 / 扁平）各画一个。

01A 静水映月 水墨 · 写意

水平线分割水面。下方是半月实形，上方是倒影虚形。一实一虚，一正一反。 水墨晕染质感——颜色不完全实，月亮边缘是渐变的。

设计逻辑
  • 实月与虚月：上方实心圆 = 真月，下方椭圆 + 渐变透明 = 水中倒影（道家「有之以为利，无之以为用」）
  • 波纹越远越虚：4 条横线表达水波，越远越细越透明 —— 真实的水面物理
  • 紫蓝渐变：月亮用紫蓝渐变而非纯色，更接近水墨晕染
01B 上善若水 极简几何

一滴下坠的水珠，下方是同心圆涟漪。一动一静，一个在落、一个在扩。 几何感最强的方案，最现代、最具产品感。

  • 涟漪四圈递减：从中心到外圈，颜色从 accent → reasoning 渐变（产品色系），透明度递减 100% → 50% → 30% → 18%
  • 涟漪扩散可做 loading 动画：四圈错峰脉冲 = 水滴思考的天然动画
01C 御风而行 印章 · 符号化

风字的篆刻笔意：用几道斜弧线代表风的轨迹，像被风吹起的衣袂。 不画风本身，画风经过的痕迹——道家「无」的美学。

设计逻辑
  • 三道风痕：风本身不可见，只能看见它经过的痕迹（吹起的沙、飘起的叶）。三道斜弧 = 三种被风吹起的东西
  • 从粗到细 = 由近到远：上方最粗（最近）、中间中等、下方最细最紫（最远）—— 透视感
  • 风端金点：风消失之处有金色灵气 —— 风也是道家「灵气」的载体
01D 动静相生 现代扁平

一根水平静水面 + 一组斜向上风线。静与动在同一画面里共存。 最简洁、最现代、最适合技术产品的方案。

设计逻辑
  • 水平 = 静，斜向 = 动：水平线（水面）= 静；斜向上弧线（风）= 动。两个基本符号代表两个意境
  • 水中有月：水平线上方的小圆点 = 月亮，水面下的小圆点 = 月的倒影（呼应 01A 但更抽象）
  • 斜线穿过水平：风从水下吹向天空——动静的边界被穿越，是「逍遥」不受限的视觉化

第 2 组 · 物与化

「虚舟、庄子蝴蝶、北冥有鱼其名为鲲。」 — 三物合一：从人到蝶到鱼，都是「逍遥」

主题：具象的逍遥载体。空船、蝴蝶、鱼三种「物」，都承载庄子的物化思想。北冥有鱼完全重画（不再用 v3 的负空间 + 渐变）。

02A 虚舟 水墨 · 写意

一只空船漂在水上，水平线分割天水。船身只用几笔勾出，没有桅帆没有人。 「虚」的极致—— 最重要的乘客（自己）不在画里。

设计逻辑
  • 空船即逍遥：庄子的虚舟故事—— 空船漂水上不会撞到人（因为没人）。这是「无我」的最强视觉化
  • 船板分隔线：竖向的几条短线 = 船的木板结构，水墨画的「皴法」笔意
  • 倒影更虚：船下方的虚影比船更虚，呼应道家「虚」的层次
02B 庄子蝴蝶 极简几何

左右对称的蝶翼 + 中央负空间身体。翅膀用半透明弧形表示， 身体是一根细线。最对称、最优雅。

  • 透明叠加：上下翅膀用 opacity 0.85 / 0.6 形成层叠感 —— 蝴蝶翅膀振动的瞬间
  • 金点 = 蝶梦核：身体上方的金点 = 庄周梦为蝴蝶时「梦境核心」的视觉化
02C 北冥有鱼 印章 · 篆刻

方框印章结构，里面一条鱼用极简篆刻笔画。 完全不同于 v3 的渐变负空间鱼——这次是印章符号语言，最东方。

  • 三笔成鱼（与 01A 同结构）：弧 + 钩 + 点，但外加方框 = 完全不同的 LOGO 语境

第 3 组 · 圆与道

「自化的圆、环中应无穷、太极、留白。」 — 四境合一：圆是最深的东方符号

主题：几何的逍遥。圆 / 环 / 太极 / 留白 —— 用 4 种调性画「圆」的 4 种哲学形态。太极做几何化处理避免中医感。

03A 自化的圆 水墨 · 写意

一笔成圆，墨韵自然扩散。圆不是画出来的，是「生」出来的。 像泼墨—— 墨滴入水，自行化圆。

设计逻辑
  • 墨韵径向渐变：从中心到边缘，颜色从 #4f8ef7 实 → 紫 → 透明 —— 模拟墨滴入水后向四周扩散
  • 中心实点：墨最浓处是中心点，最先落下的一滴 =「道生一」
  • 边缘飞溅：3 个小墨点 = 扩散过程中飞溅的余滴 ——「一生二、二生三」
03B 环中应无穷 极简几何

未闭合的环 + 内嵌的小圆。未闭合 = 永远在动；内嵌小圆 = 环中还有环，无穷无尽。 最极简的几何哲学符号。

设计逻辑
  • 未闭合 = 永远在动：闭合 = 完成 / 受限；未闭合 = 永远有下一步 —— 呼应「逍遥」的「无界」
  • 环中嵌套：外环 + 内小圆 = 环中还有环，无穷无尽。呼应「环中应无穷」原文
  • 环端箭头：缺口处的小箭头暗示旋转方向 —— 不是死的环，是动态的循环
03C 太极 印章 · 几何化

几何化处理的阴阳双鱼：避免传统太极的「中医感」， 用几何直线 + 圆点替代传统 S 曲线，更现代、更技术感。

设计逻辑
  • S 曲线 → 直线分割：传统太极的 S 曲线被替换为直线 —— 更几何、更现代，避开「中医感」
  • 上下半圆而非完整阴阳鱼：上半是阳（蓝）下半是阴（紫），但每个半圆里有一个对方颜色的「眼」 —— 阴阳互含
  • 中心金点：太极图原版无中心点 —— 我们加一个金色小点作为「道核」，让 LOGO 有视觉焦点
  • 风险：太极图在传统文化品牌里泛滥（中医、武术、道观）—— 现代品牌用它可能被认为是蹭 IP。需精修确保不像商标
03D 留白 现代扁平 · 负空间

圆形外框 + 中央大面积负空间。只在最边缘暗示一点点信息（一个破口、一个点）， 让眼睛自动补全缺失的部分 —— 最纯粹的「计白当黑」。

App icon 64px

设计逻辑
  • 几乎什么都没画：圆形外框 + 两个端点 = 整个 LOGO。这是最纯粹的「无」
  • 两个端点的语义：金点（暖 / 阳）+ 紫点（冷 / 阴）= 阴阳二气，对应留白不是死寂，是阴阳流转
  • 中央虚线圈：极淡的虚线圈暗示「中心」存在但不画实 —— 留白有度
  • 风险：极度空旷，16px 会退化成普通圆圈。favicon 退化版改为完整闭合圆 + 装饰金点
