从产品本质出发的 4 个独立方向。每个方向从「产品核心动作」反推符号，不依赖文化隐喻。 所有 SVG 严格使用 design-tokens.md 的语义色（accent / reasoning / warn），与产品 UI 视觉系统天然融合。

从产品反推符号

xyz-agent 是 AI coding agent。核心动作：思考 → 执行 → 验证。符号应映射这三种动作，不是鱼鸟。

16px 鲁棒性

浏览器 tab favicon、macOS 菜单栏图标、Linux 系统托盘——最小可用尺寸 16px，必须保证识别度。

语义色 > 装饰色

只用 design-tokens 里已有的颜色变量。新增颜色 = 引入技术债，未来主题切换会断。

纯几何，可矢量

只使用基本路径（circle / rect / line / simple curve）。AI 生成图不收——不可二次改、不可缩放。

DIR · 01 节点连接器 node-network / agent-think
agentic 技术产品主流 几何对称 缩放性 ★★★★★

AI agent 的本质是「节点网络 + 数据流」。用 3 个节点 表达「用户 → agent → 代码」三方关系， 节点间的连接线表达「思考 / 行动 / 反馈」的流动。从 Cursor/Windsurf/Cline 等主流 AI coding 工具看， 「节点 + 连线」是这个赛道的视觉共识——大家都能一眼识别这是 agent 工具，差异化靠几何比例和细节。

DIR · 02 流动之环 agent-loop / think-act-verify
闭环 motion 优先 极简 缩放性 ★★★★★

Agent 的核心是 think → act → verify 的循环（ReAct / Tool-use 范式）。 用「未闭合的圆弧 + 一个方向点」表达这个循环：永远在转，永远有下一步要做——呼应「逍遥」的「无界、流动」内核。 比方向 A 更抽象，但 motion-first（启动动画 / loading）天然契合产品节奏。

设计逻辑
  • ReAct 范式的视觉化：think→act→verify 的循环是当前所有 agent 的范式，「循环箭头」直接对应这个产品 DNA
  • 未闭合 = 永远在思考：3/4 圆环开口在右上，像「话说到一半被打断、永远有下一步」—— 呼应逍遥「流动无界」的哲学
  • 箭头朝向独特：3/4 圆 + 右上方向箭头（不是常规的圆形 logo 顺时针/逆时针），方向感比纯环更强
  • 中心点 = 思考核心：内层 accent 蓝实心 + reasoning 紫虚线环 = 「此刻正在思考」的视觉隐喻，做 loading 时中心点呼吸即可
  • 风险：「循环箭头」类符号较常见，需靠「3/4 圆 + 不对称开口 + 箭头方向」做出辨识差异
DIR · 03 F×W 字母构 lettermark / dual-name
lettermark 极简 国际化 缩放性 ★★★★★

直接用品牌名首字母 F × W（Free × Wise）做几何构型。 Linear / Vercel / Figma / Replit 都用字母 mark，证明这是技术产品最经久不衰的范式。 「F 上 W 下」的双行排版比单字母更独特，承载「Free + Wise 二元一体」的产品哲学。

设计逻辑
  • 命名直接映射：F = Free（蓝/锐利），W = Wise（紫/有起伏）—— 不需要任何文案解释就能读出品牌名
  • 几何最简：只用 line + stroke，F 的三笔 + W 的四笔，没有任何曲线/装饰元素
  • 亮色模式天然适配：字母 mark 在白底/浅底表现力强，logo 自动适配浅深主题
  • 风险：16px 退化必须丢掉一个字母（变成单 F 或单 W），与主标视觉割裂；lettermark 在 AI 工具里非常常见（Cursor/Cody/Cline），差异化难
  • 备选：可改为「W 上 F 下」「F+W 上下叠」等不同组合，但 F 上 W 下最有「Free 主导 + Wise 辅助」的产品语义
DIR · 04 双推控制 dual-slider / free-wise-control
概念最独特 控制感 产品基因 缩放性 ★★★★☆

产品名「逍遥 FreeWise」暗示 两种力的平衡：Free = 自主/放手，Wise = 精确/控制。 用「两根平行滑轨 + 两个对向的滑块」表达：不是只有一个旋钮，是 Free 和 Wise 两个独立可调的维度。 这是 4 个方向里 概念最独特 的——其他 AI 工具都是单点，xyz-agent 是双维调节。

我的判断（仅作参考，最终你定）

如果只能选一个：方向 04「双推控制」。 理由：xyz-agent 的核心体验差异点是「Free × Wise 的双维控制」（用户可以调自动/手动粒度），不是「也是个 AI agent」。LOGO 应当承载这个差异点。其他方向都能套用到任何 AI 工具上，方向 04 只有 FreeWise 能用。

备选：方向 02「流动之环」。 如果你认为产品定位是「agent 的循环思考」而非「双维控制」，方向 02 的循环+未闭合 + motion-first 是最 timeless 的选择，且 16px 鲁棒性最好。

不建议主标的：方向 01（节点网络）和方向 03（F×W 字母构）。 01 是赛道视觉共识，差异化太难；03 的 lettermark 在 AI 工具里太多（Figma/Linear/Replit/Vercel 都是），缺乏独占感。

下一步：你选定方向后，我做该方向的 几何精修稿 —— 调比例 / 调描边 / 调配色权重，确保 favicon 16px 仍清晰，并补 SVG 源文件。
