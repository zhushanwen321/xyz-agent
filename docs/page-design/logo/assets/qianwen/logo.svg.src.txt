# qianwen 双鱼太极 logo (最终版)

来源: 千问 AI 生成的双鱼图 (见 source.png.src.txt)
几何来源: potrace 自动追踪 (见 logo-autotrace-raw.svg.src.txt), 保留全部 6 条 path 的 d 属性
后处理: 加 fill/stroke 让"白鱼白身黑线/黑鱼黑身白线"显式成立, 跨背景色可移植

## 设计

- viewBox: 0 0 857 1224 (与源图同比例, 竖向 200x285 默认显示)
- 黑鱼: fill=#000000 完整填充 (含黑鱼身/鳍/尾), stroke=#ffffff 加白线条
- 白鱼: fill=#ffffff 显式填充, stroke=#000000 加黑线条
  (用 g 分层 + potrace 的 path 自然形成"白鱼身是黑鱼区域外的洞")
- 鱼眼: 显式 ellipse (按 PIL 几何分析位置):
  - 白鱼眼: cx=392 cy=464, 51x21 黑椭圆
  - 黑鱼眼: cx=271 cy=283, 53x11 白椭圆
- 鳍线装饰: 保留 potrace path[4][5] 的小鳍线, fill=none stroke=black
