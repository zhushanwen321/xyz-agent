# logo PNG (位图版本)

来源: logo.svg 通过 headless Chrome 渲染 (http://127.0.0.1:8766/_render.html)
尺寸: 857 x 1224 (与 SVG viewBox 同比例)
格式: PNG, RGB, 无透明背景 (默认白底)

## 渲染方法 (复刻命令)

```bash
# 1. 启 http server (Chrome headless 不支持 file:// 下的 inline SVG 渲染)
cd docs/page-design/logo/assets/qianwen
python3 -m http.server 8766 --bind 127.0.0.1

# 2. 生成 inline-SVG HTML 包装
python3 -c "
svg = open('logo.svg').read().replace('<?xml version=\"1.0\" encoding=\"UTF-8\"?>\n', '')
open('_render.html', 'w').write(
  '<!DOCTYPE html><html><head><style>html,body{margin:0;padding:0;background:white}svg{display:block;width:857px;height:1224px}</style></head><body>' + svg + '</body></html>'
)"

# 3. headless Chrome 截图
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu --no-sandbox \
  --hide-scrollbars --window-size=857,1224 --default-background-color=00000000 \
  --screenshot=logo.png "http://127.0.0.1:8766/_render.html"

# 4. 清理临时文件
rm -f _render.html
```

## 用途

- 不需要 SVG 缩放能力的场景 (Markdown/README 嵌入、社交媒体头像、CI 截图)
- 透明背景版: 改 `background:white` 为 `background:transparent`, 但 Chrome --default-background-color=00000000 已部分处理, 边缘可能有 1px 白边, 需要用 imagemagick/inkscape 后处理
- 任意尺寸缩放: 改 `--window-size` 即可, 矢量几何不会失真

## 不推荐的替代方案

- ❌ cairosvg: 缺 cairo 系统库 (`brew install cairo` 单独装)
- ❌ rsvg-convert: brew 装 librsvg, 但 lottie 类的 path 可能渲染不一致
- ❌ Chrome 直接 file:// 渲染 SVG: 不会画图, 只会显示空白窗口
- ❌ Chrome 加载 <img src="logo.svg">: file:// 下 CORS 拦截
