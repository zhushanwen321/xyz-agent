# logo square — 1:1 正方形版（撑满版）

来源: 基于 logo.svg (v1 双鱼版) 改造为 1:1 正方形 + 撑满
用户 2026-08-02 需求:
  v1: "将 V1 版本 logo 做成正方形的 SVG 和 PNG"
  v2: "预留空间太大了, 希望是 LOGO 比较撑满的状态"

## 迭代过程

| 版本 | scale | 留白 | 评价 |
|------|-------|------|------|
| v1 (0.7) | 0.7 | ~30% | 用户反馈"留白太大" |
| v1.1 (1.4) | 1.4 | ~5% | 鱼头顶到画布顶端, 太满 |
| **v1.2 (1.32)** | 1.32 | ~10-15% | **当前采用, 鱼头完整+撑满** |

## 当前实现 (v1.2)

```svg
<svg viewBox="0 0 1200 1200">
  <g transform="translate(62, -271) scale(1.32)">
    <g transform="translate(0,1224) scale(0.1,-0.1) translate(-21.334,980.869)">
      <!-- 6 条 potrace path 不动 -->
    </g>
  </g>
</svg>
```

**几何计算**:
- 鱼原 bbox (20,243)-(807,977), 尺寸 787×734
- scale 1.32: 鱼 1039×969
- translate(62, -271): 让鱼 x 范围 88.5-1127.5 (占 x 86.6%), y 范围 50-1019 (占 y 80.7%)
- 留白约 13-19% (顶部 50px, 底部 181px, 左右各 88.5px)
- 视觉重心居中 (相比 v1 的 +50 微调, 这里因为鱼 y 起点 50 已经有顶部 padding, 视觉上居中)

## 与 logo.svg (竖向版) 的差异

| 维度 | logo.svg 竖向版 | logo-square.svg 正方形版 |
|------|----------------|------------------------|
| viewBox | 0 0 857 1224 | 0 0 1200 1200 (1:1) |
| 宽高比 | 0.7:1 | 1:1 |
| 鱼大小 | 787×734 (原图大小) | 1039×969 (scale 1.32) |
| 占 viewBox | 92%x60% | **86.6%x80.7%** |
| 留白 | 上下 ~250px (20% 上下) | ~13-19% (撑满) |

## 何时使用

| 场景 | 推荐版本 |
|------|----------|
| 文档封面/落地页 hero (竖向) | logo.svg (v1) |
| favicon / 头像 / App icon (正方形) | **logo-square.svg** |
| Markdown 嵌入 (无 SVG 支持) | logo-square.png (1200x1200) |
| Open Graph 图 | logo-square.png |

## 注意事项

- **鱼头贴画布顶端** (y=50 处) — 这是"撑满"设计, 不是 bug
- 如果需要更安全边距, 把 scale 改 1.2, 留白 ~25%
- 矢量, 无损缩放任意尺寸
