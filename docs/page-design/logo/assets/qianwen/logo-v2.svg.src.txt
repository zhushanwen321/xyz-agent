# logo v2 — 阴鱼版（负空间版）

来源: 基于 logo.svg (v1 双鱼版) 改造，删除阳鱼部分
用户 2026-08-01 需求: "制造更多负空间感觉，只保留阴鱼，把阳鱼做成负空间"

## 与 logo.svg (v1) 的差异

| 元素 | v1 双鱼版 | v2 阴鱼版 |
|------|----------|----------|
| 黑鱼身 (path[0]) | 保留 | 保留 |
| 黑鱼右鳍/尾鳍 (path[3]) | 保留 | 保留 |
| 黑鱼身装饰小鳍线 (path[4]) | 保留 | 保留 |
| 白鱼身/白鱼鳍/白鱼尾 (path[1]) | 保留 | **删除** |
| 白鱼身轮廓线 (path[2]) | 保留 | **删除** |
| 白鱼身装饰小鳍线 (path[5]) | 保留 | **删除** |
| 白鱼眼 (黑椭圆 cx=392 cy=464) | 保留 | **删除** |
| 黑鱼眼 (白椭圆 cx=271 cy=283) | 保留 | 保留 (在黑鱼身上挖洞，暗示"阳眼") |

## 视觉效果

- **白底场景**: 一尾游动的黑鱼 + 大片负空间，阳鱼作为"想象/暗示"存在
- **黑底场景**: 黑鱼融入背景，视觉极简（如果需要深色版需要整体反色，见 v3 计划）
- **更克制/极简**: 比双鱼版少了一半元素，更符合"克制"设计原则
- **太极图暗示**: 即使没有阳鱼，观者仍能脑补"鱼在太极图中游动"

## 何时使用

| 场景 | 推荐版本 |
|------|----------|
| 完整展示双鱼结构/品牌建立初期 | logo.svg (v1) |
| 应用图标/favicon/小尺寸 | logo-v2.svg (v2，更易识别) |
| 极简风格/暗色背景 | logo-v2.svg (v2) |
| 文档封面/落地页 hero | logo.svg (v1) |

## 不删除 v1 的原因

- 客户/老板可能想要完整双鱼版（"完整呈现"）
- v1 + v2 互为补充，提供设计选择空间
- 修改/回退成本几乎为零（都基于同一份 potrace 几何）
