# potrace 原始输出 (几何参考底稿)

来源: potrace 1.16 自动追踪 source.png
命令: potrace -s source.pbm -o logo-autotrace-raw.svg --tight --turdsize 2 --opptolerance 0.2
特性: 单色 fill=#000000, 6 条 path, 6.3KB

## 与 logo.svg 的关系

此文件保留作为**几何数据参考底稿** — 6 条 path 的 d 属性是 logo.svg 矢量几何的来源。
**不要直接用**此文件作为 logo (单色无描边, 整体偏小, 缺白鱼身显式填充)。

## 6 条 path 的角色

| path | 角色 |
|------|------|
| [0] | 黑鱼身/黑鱼头主轮廓 (大块黑) |
| [1] | 黑鱼身外缘 (含右鳍) |
| [2] | 白鱼身/白鱼鳍/白鱼尾 (千问图中是黑线画在白底) |
| [3] | 黑鱼右鳍/尾鳍 (千问图中是黑鱼尖角) |
| [4] | 黑鱼身装饰小鳍线 |
| [5] | 白鱼身装饰小鳍线 |
