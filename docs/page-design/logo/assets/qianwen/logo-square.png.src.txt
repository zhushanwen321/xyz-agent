# logo square PNG (1:1 正方形位图版本)

来源: logo-square.svg 通过 headless Chrome 渲染
尺寸: 1200 x 1200 (1:1 正方形)
格式: PNG, RGB, 无透明背景 (默认白底)

## 渲染方法

与 logo.png.src.txt 相同, 区别:
- 输入: logo-square.svg (替换 logo.svg)
- window-size: 1200x1200 (替换 857x1224)
- 输出: logo-square.png (替换 logo.png)

详见 [logo.png.src.txt](logo.png.src.txt).

## 用途

- App icon (iOS/Android/Web) 必需正方形
- favicon: 浏览器 favicon 通常从 1:1 PNG 自动缩放
- 头像: 圆形裁剪从正方形来最自然
- Open Graph 图: 1200x630 是常规尺寸, 但 logo 部分是正方形合适

## 缩放

logo-square.svg 是矢量的, 无损缩放任意尺寸.
但 1200x1200 渲染对应 SVG 默认尺寸, 渲染更快.
