Composer

输入框完整规格。自上而下 7 区：RetryIndicator → QueueBubble(§8.5) → composer-box（staging chip / ContextChipsBar / landing meta-row / Input / composer-bar 工具条）。landing 与 panel 两态视觉本体相同，差异仅在宽度、meta-row、slash 命令源。附件 8 种插入路径，4 种内联 chip（紫绿蓝 + image 紫）。staging fork/handoff 两模式（经 useComposerStaging 统一编排）。composer-bar 四个 popover。发送位 4 态状态机。键盘路由全表见 9H。
