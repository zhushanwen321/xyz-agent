v6 DEMO · plugin 能力上限全景

Plugin 能定制哪些地方？ · Pipeline Commander

虚构一个最大化自定义的 plugin「Pipeline Commander」（DevOps 流水线管理），在单个 AppShell 全景界面里同时点亮全部 16 个挂载点（M1-M16），展示 plugin 通过布局位置（5 维度）和组件原语（7 原语）到底能在哪些地方做定制、定制成什么样。每个挂载点贴 M编号 标签，颜色对应所属维度。这不是产品截图，是能力上限的视觉证明——假设一个 plugin 把所有能改的都改了，长这样。

维度 A · 结构容器（sidebar/drawer tab · 工具条 · 底栏） 维度 B · 对话流内容（tool result · custom message · ask-user） 维度 C · 交互对话框（confirm/select · overlay 窗口化） 维度 D · 命令配置（slash command · settings schema） 维度 E · 独立 view（完整路由，仅 built-in）

§3

16 挂载点能力清单 · Pipeline Commander 用了什么

逐条列出这个 plugin 在每个挂载点用了什么原语、什么自定义级别、external 是否可用。这是「plugin 能力上限」的结构化总结——16 个位置就是 plugin 能改的全部地方，超出这个范围的事它做不到。

挂载点 位置 维度 级别 Pipeline Commander 用了什么 external 可用
M1 sidebar · 一级 tab A 结构容器 L1 第5独立 Puzzle tab（元数据声明 placement:'sidebar'），renderer 固定宿主渲染 ✓ 全部
M2 sidebar · 子视图 A 结构容器 L2 二级 tab「Pipelines/Targets/History」+ list-tree 原语渲染 pipeline 步骤（done/running/failed 圆点） ✓ 全部
M3 sidebar · footer A 结构容器 L1 不改结构，Settings 齿轮入口指向含 plugin 区段的设置页（M16） ✓ 全部
M4 main · 对话流 block B 对话流 L2 tool result __gui__ = card(header badge) + stats-line + progress-bar 组合 ✓ 全部
M5 main · custom message B 对话流 L2 主动推送 __gui__ widget = columns(左 list-tree + 右 card+progress-bar)，证明 7 原语组合表达力 ✓ 全部
M6 drawer · tab 栏 A 结构容器 L1 drawer 一级 pipeline tab（icon）。注：v6 决策 plugin view 集中 sidebar，drawer 暂不开放，此为未来扩展位 △ 未来
M7 drawer · 内容 A 结构容器 L2 ansi-text 原语渲染部署日志（ANSI 16色→v6 语义色：red→danger / green→success） ✓ 全部
M8 AppShell · 全局底栏 A 结构容器 L1 4 个 statusBarItems：pipeline running / e2e failed(warn) / build blocked(danger) / target staging。priority + alignment 排序，跨全宽常驻 ✓ 全部
M9 composer · 工具条 A 结构容器 L1 2 个 icon 按钮：快速部署（带 count=2 徽章）/ 日志。icon 14px stroke 1.75，点击触发 command ✓ 全部
M10 composer · 命令面板 D 命令配置 L1 3 个 slash 命令：/deploy / /rollback / /pipeline-status，CommandPopover 统一渲染，带 plugin 标识 ✓ 全部
M11 composer · companion B 对话流 L1 ask-user 富交互（双向通道）：e2e 失败后询问是否继续部署，3 选项单选。可最小化为 badge（C3） ✓ 全部
M12 main · panel header A 结构容器 L1 2 个 header 按钮：pipeline 状态（带 count=1）/ 快速部署。1px hairline 分隔 plugin 组与内置 ✓ 全部
M13 main · 浮层 slot B 对话流 L2 对话流浮层（load-more/fork/jump）——低优，本 plugin 未使用，预留扩展位 ✓ 全部
M14 全局 · 独立 view E 独立 view L3 完整 view 路由「Pipeline Dashboard」（与 chat/overview 同级），预编译 Vue 组件，columns+list-tree+progress-bar 全屏布局 ✗ 仅内置
M15 全局 · modal C 对话框 L1 confirm dialog（确认部署到 production）+ C3 窗口化（最小化 badge / 拖动）。统一 DialogRequest 协议 ✓ 全部
M16 Settings · 区段 D 命令配置 L1 contributes.configuration schema → settings 页自动渲染：api endpoint(string) / auto deploy(bool) / environment(enum) / timeout(number)。复用 settings 控件 ✓ 全部
