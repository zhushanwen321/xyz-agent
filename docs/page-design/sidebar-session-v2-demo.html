未读标记规则

  • 未读 = 7px accent 圆点叠在状态 icon 右上角（absolute，box-shadow 镂空边框）
  • 用户 select 这个 session 时自动清除未读
  • 已归档 session（markedDone）的 unread 自动清除
  • done + 已读 + 已归档 → 左侧完全空白，标题 opacity-0.6

对比当前实现的变化

  • 去掉：右侧 badge 矩阵（running 呼吸竖条 / waiting … 胶囊 / error ! 胶囊）
  • 去掉：左侧 8px 未读占位圆点
  • 新增：左侧 7px 状态 icon（旋转箭头/空心圆/实心圆/空白）
  • 保留：未读标记（accent 圆点）、选中态（bg-surface + 蓝字）、hover ghost 操作、dead opacity-50
  • 简化：streaming/compacting/working/retrying 统一旋转箭头（它们都是「正在运行」语义）

与 v6 spec 的对齐关系

  • v6 spec §3.3 定义了 7px 圆点范式：done=success 90% / running=accent / waiting=warn / error=danger / dead=neutral-dim
  • v2 demo 继承了 v6 的圆点色阶，但把 running 从「实心 accent 圆点」改为「旋转箭头」（增加动态辨识度）
  • v2 demo 新增了 pending（空心圆）和 stopped（dim 空心圆），v6 spec 未区分这两个态
  • v2 demo 移除了右侧 badge 矩阵（v6 spec §5.6A 的「左未读点 + 右异常 badge」），改为左侧单一 icon
  • 未读标记保持 v6 范式：7px accent 圆点，absolute 叠在状态 icon 右上角
