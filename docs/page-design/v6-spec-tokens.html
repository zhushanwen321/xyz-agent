新增 token · 三层明度

v6 新增 3 个 token。核心是「三层明度」——stage 深底(#0a0a0c) → 画布(侧栏/drawer = bg，靠 --bg-sunken 表达) → 主面板 surface 浮起。--bg-sunken 语义变更：原 visual-modernization 用 color-mix(bg 97%, black) 把侧栏往黑推导致发脏，v6 改为与画布同色融合，靠主面板浮起分隔，对标 Claude/Linear。

z-index 语义化

现状混用 z-[1] / z-10 / z-[1000] 任意值。v6 定义 4 档语义 scale，逐处替换。

base正常文档流（panel 内容）
--z-sticky1 · sticky 贴顶（TurnMeta / 列表组标题）
--z-popover10 · popover / dropdown
--z-overlay20 · overlay（AskUser / drawer 抽屉）
--z-modal1000 · modal（SearchModal / FullSettings）
Token值用途
--z-sticky1sticky 贴顶元素（TurnMeta、列表组标题）
--z-popover10popover / dropdown menu / tooltip
--z-overlay20overlay（AskUserOverlay、SideDrawer 抽屉）
--z-modal1000modal（SearchModal、FullSettingsOverlay、ConfirmDialog）
（无 token）9999Toast · z-9999 固定值例外（跨 modal 层级最顶显示，design §5.2 登记）
反写位置: style.css :root 新增 4 个 --z-* token + 逐处替换任意 z 值

§8

标注格式规范

后续 v6-spec-*.html 统一采用本标注格式。每个组件元素附「px 值 + token 引用 + 状态差异」三重标注，实现后可逐元素比对验证。

// 单元素标注格式 组件名 [状态] ├─ padding: 12px [var(--space-3)] ├─ border-radius: 8px [var(--radius)] ├─ background: var(--surface) ├─ color: var(--neutral-fg) ├─ font: 13px/1.5 [var(--text-base)] └─ 状态差异: hover→bg-surface-hover; focus→accent-ring // 规则 // 1. px 值在前，token 引用方括号在后 —— 既可肉眼验证，又可反写代码 // 2. v6 变更项用 success 色，保留项用 neutral 色 // 3. 状态差异列全：default / hover / focus / active / disabled / error / loading / empty // 4. 标注用 mono 字体（--font-mono）+ neutral-mid 色，与组件视觉分离
