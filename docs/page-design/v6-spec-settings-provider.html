provider 行的 status（connected / not_configured / error）与 enabled（开/关）的交叉矩阵，定义每种组合的点色、Switch 态、可交互性。供实现时逐格比对。

status 状态点 enabled = true enabled = false 说明
connected success / .9 · 7×7 Switch on(accent) · 名称可展开 · 默认 pill(若 defaultModel) Switch off(surface-hover) · 仍可展开/编辑 已配 key 且最近连接成功。最高频态。toggle 走乐观更新。
not_configured idle neutral-dim · 7×7
旧：无明确点		 Switch on · 但实际未配 key，首次调用会失败 Switch off（默认）· 鼓励先编辑补凭据 M6 修复：补 idle 中性点。未配置 key 的待激活态。
error danger · 7×7 Switch on · 点显 actionError（连接失败原因） Switch off · 名称仍可展开查看凭据 已配 key 但连接失败（401/超时等）。actionError 非静默。
