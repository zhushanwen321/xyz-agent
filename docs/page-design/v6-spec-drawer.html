§2

二级 tab 架构（形态 B）

Drawer 采用「形态 B：icon 一级 + 内层二级（按需出现）」。每个一级 tab 是独立页面，二级 tab 由各 tab 组件自行定制——drawer 框架不统一管二级。只有内容支持多实例的一级 tab（detail 多文件 / terminal 多实例）才显示二级 tab 栏；单一内容 tab（git/doc/tasks）不显示，避免「假二级」。对标 VS Code「侧栏 icon + 编辑器 tab」的双层模型。

现 useDetailPane 单例（单值驱动） v6 形态 B：icon 一级 + 内层二级（按需） v6 detail 多文件 / terminal 多实例
