# 配色决策：太极纯灰重克制（V3）

> 日期：2026-08-02
> 性质：临时决策文档（换色落地前的方向固化，落地后合并进 `design-tokens.md` SSOT）
> 前置：本决策改变的是**色相**，不改变 v6 的明度阶梯、圆角档位、间距体系、布局拓扑
> 对比稿：[`palette/taiji-pure-restrained-v3.html`](./palette/taiji-pure-restrained-v3.html)（临时探索稿，不进 git）

---

## 一、背景

用户想把整个产品做成符合**太极 / 阴阳鱼 / 圆 / 相生相克 / 周而复始**概念的风格。当前 v6 是冷蓝暗色系（`--bg #1a1b1f` / `--accent #4f8ef7`），与太极概念无关。

经三轮对比后确定方向：
1. 三套色相方案对比（墨青 / 墨朱 / 纯太极）→ **选定纯太极**
2. 纯太极 4 档克制梯度对比（浅 / 中 / 重 / 极简灰度）→ **选定重克制（V3）**

被否方案及理由：

| 方案 | 否决理由 |
|------|---------|
| 墨青（accent `#3a9b7e`） | 青绿色虽东方，但基底仍是冷色系，太极的"黑白"纯粹感不够 |
| 墨朱（accent `#c95543`） | 朱砂红在暗底上久盯会燥，且红天然关联 danger 语义冲突 |
| 纯太极浅克制 V1 | 状态色仍偏鲜艳（`#6fcb8a` 亮绿等），水墨的克制感不足 |
| 纯太极中克制 V2 | accent `#d4d4d8` 仍偏亮，过曝感残留 |
| 纯太极极简灰度 V4 | 状态色完全零色相，M/A/D 变更集 badge 无法靠颜色分辨增删改，语义损失过大 |

## 二、太极概念的三层拆解

V3 只解决其中一层（色），另两层是独立工作线，不并进本次换色：

| 层 | 对应 UI | V3 是否覆盖 |
|----|---------|------------|
| **色**（阴阳 / 相生相克） | 主色、明暗对比、状态色 | ✅ 本次覆盖 |
| **形**（圆 / 环） | 圆角档位、环形进度、徽章形态 | ❌ v6 现在刻意棱角（6/8/12px），若要太极感需另开工作线（加大圆角 / S 曲线分割） |
| **动**（周而复始） | loading 动画、过渡曲线 | ❌ 现在是 `cubic-bezier(0.4,0,0.2,1)`，无循环语义，可考虑太极旋转 loader |

### 非色彩 token（不变，沿用 v6）

字体 / 字号 scale / 圆角 / 间距 / 阴影 / 动效 / `--content-max-w` 全部不变。

### 亮色变体（待补）

亮色变体需镜像重调（bg 最浅 → surface 纯白 → 灰阶递进）。本次决策只定暗色（默认主题），亮色作为降级变体在落地阶段补全，保持同灰度阶梯。

## 四、落地前置条件（非可选）

**在换色之前，v6 的结构性半改项必须先收敛**，否则冷蓝色会从没改干净的缝隙里冒出，且三真值源（design / spec / demo）已知的 6 个方向性分歧会让换色后的对色工作无法进行。

前置清单（源自 [`v6-review-round2-2026-07-31.md`](./v6-review-round2-2026-07-31.md)）：

## 五、落地步骤（严格顺序）

### 第一步：v6 结构收敛

执行 §4 全部前置项。**不碰色相**，只让"所有颜色都走 token"这件事成立，以及让三真值源方向一致。

### 第二步：整族色相重调（核心换色）

改两处 SSOT 的 `:root`：
- [`design-tokens.md`](./design-tokens.md)（文档 SSOT）
- [`v6-spec-tokens.html`](./v6-spec-tokens.html)（实施 SSOT）

把冷蓝灰全族替换为 §三 的 V3 纯灰系。关键约束：
- 明度阶梯保持不变（v6 多轮校准的对比度关系不能丢）
- `--accent-soft` / `--accent-ring` 走 `color-mix` 会自动跟随，只需改 `--accent`
- `--bg` / `--surface` / `--neutral-*` 全族必须一起换，否则冷暖斑驳

### 第三步：真值源同步 + 验证

1. 18 个 spec HTML 的 token 块同步（都是 `v6-spec-tokens.html` 的拷贝）
2. `v6-demo.html`、Vue demo（`v6/`）同步
3. headless Chrome 截图对比：换色前后，确认无冷蓝色从任何缝隙冒出
4. WCAG AA 对比度复核（`--neutral-fg` on `--bg`、`--neutral-mid` on `--surface` 等关键组合）

## 六、关于"形"与"动"两层（后续独立工作线，本次不做）

若要让太极感更完整，后续可考虑（不在本次换色范围）：

- **形**：圆角档位整体上调（如 `--radius-sm` 6→8px，引入更多圆形元素），或引入 S 曲线 divider 替代直线 border
- **动**：loading 动画做成旋转太极，过渡曲线考虑带回弹的 ease 体现"消长"

这两层需要单独的设计探索和 demo 验证，不并进本次色相换色。
