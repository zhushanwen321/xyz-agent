流程完整路径与状态机

从 directory chip 到远程连接成功的完整交互路径：

① composer 顶 directory chip（空态「选择工作区」）
　↓ 点击
② directory popover（搜索 + 最近 + 动作）
　↓ 点「远程连接」动作（v1 stub 实化）
③ 关闭 popover，打开「远程连接」modal（landing 模糊背景）
　↓ modal 内三 tab：粘贴 / 手动 / 已保存
④ 粘贴引导字符串 → 解析 URL+Token（或手动填，或选已保存）
　↓ 点「连接」
⑤ WS 握手 + token 认证 + initial state（modal 内进度）
　↓ 成功　↓ 失败
⑥a 关闭 modal，chip 填入远程目录，显示「远程模式」状态条
⑥b modal 内显示错误，可重试 / 切换 tab / 取消
