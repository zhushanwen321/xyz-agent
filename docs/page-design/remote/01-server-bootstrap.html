服务端首启输出 · 引导连接

runtime 首次启动（检测到 ~/.xyz-agent/token 不存在）自动生成 token，输出三种形态的连接信息：APP deep link、URL+Token 文本、QR 码。客户端复制任一即可连接。详见 docs/feature-map/2026-07-26-remote.md §6.3。

场景：服务端 CLI 首启 输出形态：3 种 探测优先级：PUBLIC_URL > Tailscale > 局域网 IP
user@server — zsh — 120×40
➜ ~ /xyz-agent-runtime --host 0.0.0.0 --port 3210 --print-qr
✓ xyz-agent server started (runtime v0.9.0, pi v0.80.3)

ℹ token generated: ~/.xyz-agent/token (mode 0600)
ℹ pi executable: /usr/local/bin/pi
── 复制下面任一内容，粘贴到客户端即可连接 ──

[QR] 二维码 · 手机扫码（默认内容 = [1] 浏览器直达）

手机浏览器扫码直接打开 Web 端，

装了 APP？ 加 --qr deep-link

补充可达 URL 自动探测优先级

runtime 启动时按以下顺序探测，输出第一个命中的 URL（默认只输出一个最优解；--print-all-urls 可输出全部）：

# 优先级从高到低：
1. XYZ_AGENT_PUBLIC_URL env（用户显式指定，反代场景必填）
2. Tailscale IP（检查 tailscale0 网卡 / tailscale status --json）
3. Tailscale MagicDNS 名（<host>.<tailnet>.ts.net，需 MagicDNS 开启）
4. 局域网 IP （非 loopback 的 IPv4）
5. fallback: ws://localhost:<port>
Tailscale 优先于局域网 IP 的理由：Tailscale 跨网络可达（手机 4G 也能连），局域网 IP 仅同 WiFi 有效。检测到 Tailscale 时默认输出 Tailscale URL。
