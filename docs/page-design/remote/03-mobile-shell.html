B多设备协同 · presence 显示

抽屉底部「在线设备」列表展示当前连到同一服务器的所有设备（多客户端协同，§4.1 协同语义）。正在操作 pi 的设备标记「操作中」，对应 session 列表项也显示占用指示。

presence 数据来源：runtime 通过 presence.update 事件广播连接列表（上线/下线/切换 session/操作状态变化），前端 stores/presence.ts 维护。详见 §8.4 P6。
单用户多设备语义：所有设备共享同一 token，都是「同一用户的设备」，presence 只展示设备名（如 MacBook Pro / iPhone），无需用户账号体系。

C移动端砍除的桌面专属功能

这些功能在移动端砍除或简化，不影响核心 chat/file/git 流程（§8.3）：

砍除（移动端无意义）
• TrafficLight 红黄绿窗口按钮
• pt-[52px] macOS 安全区留白
• [-webkit-app-region] 拖拽区
• BrowserPane 嵌入式浏览器 drawer（WebContentsView，移动 WebView 无对应）
• 全局快捷键（onShortcut，移动无键盘）
• 多窗口 API（createWindow 等，renderer 本就零调用）
简化/替代
• openExternal → 系统浏览器打开（Capacitor Browser/OpenUrl）
• pickDirectory → 服务端目录树 RPC（dir.list）
• local-file:// 图片 → HTTP 端点 + blob URL
• 完成提示音 → Web Audio（需用户先交互，autoplay policy）
• onFullscreenChanged → 降级恒 false 或用 Fullscreen API
