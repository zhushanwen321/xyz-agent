客户端连接入口

三种客户端形态的首连体验：手机/电脑浏览器地址栏直粘（推荐最短路径）、桌面 APP 欢迎屏（剪贴板探测）、手机 APP 扫码/微信转发。统一规则：复制服务端输出的连接字符串，浏览器粘贴地址栏 / APP 粘贴框 / 扫码即可连接。详见 §6.4。

客户端：3 种形态 核心交互：地址栏直粘 / 粘贴框 / 扫码 最短路径：浏览器地址栏粘贴 HTTP URL 剪贴板探测：仅未连接时 · 不自动连接

A手机/电脑浏览器 · 地址栏直接粘贴（最短路径 · 推荐）

服务端终端复制 http://<host>:3210/#token=...，直接粘到浏览器地址栏（手机先装 Tailscale 加入 tailnet）。浏览器打开 Web 端，JS 从 hash 读 token、从 host 推 WS 地址，自动连接。无需装 APP、无需手动填。

手机浏览器 · 地址栏直粘 HTTP URL
最短路径 · 3 步
1. 服务端终端复制 http://...#token=...
2. 手机装 Tailscale + 浏览器地址栏粘贴
3. Web 端自动识别 → 点「连接」
为什么用 hash fragment
#token=... 不发给服务器、不进 access log、不被 Referer 泄露。JS 读 hash 拿 token，从 location.host 推 WS 地址（同源，无需额外配置）。
后续访问
连接成功后 token 存 localStorage，下次直接访问 http://host:3210/（书签即可，不用再带 token）。

剪贴板探测安全约束：(1) 只在「未连接」状态探测；(2) 探测到后不自动连接，必须用户点「连接」确认（防恶意剪贴板自动触发）；(3) 解析失败静默忽略。窗口聚焦（focus / visibilitychange）时重新探测——适配「在服务端 SSH 里复制 → 切回 APP」的工作流。

CWeb 网页端 · 粘贴框（兜底 · token 失效或跨源场景）

如果直接访问 Web 端 URL 但 #token 缺失/失效（或 Web 与 WS 跨源部署），首屏提供「粘贴连接信息」输入框。支持粘贴 [1] HTTP URL / [2] deep link / [3] 多行 URL+Token 三种格式。

粘贴连接信息（支持 HTTP URL / deep link / 多行）
Web 端解析容错：粘贴 xyz-agent://connect?... → 解析出 url+token；粘贴 ws://... 单行 → 自动填 URL，提示粘 token；粘贴「URL: ws://... Token: ...」多行 → 正则解析两行。三种格式都支持，对用户复制行为容错。

D手机 APP · 三条路径（装了 APP 的场景）

手机 APP（Capacitor）首连有三条路径：扫码（默认扫 [1] HTTP URL，APP 内 WebView 打开；或扫 [2] deep link，唤起原生）、微信收 URL → 复制 → 打开 APP（剪贴板探测）、deep link（点 xyz-agent:// 唤起）。没装 APP 的用户直接走 A 场景（浏览器地址栏直粘）。
