TurnSummary · hover actions（copy/fork/handoff · 方案 A 扁平 3 按钮）

每个 assistant 回复底部的动作入口，是对话流最核心交互入口。v6 重设计采用 方案 A：去掉 split-button 副选项浮层、去掉 MD/+Q badge，改为单层 3 个 icon button（copy / fork / handoff）。点击 fork/handoff = 默认进入「+Q 变体」（带提问）；composer 直接 enter = 无内容变体（等效原无 +Q 逻辑）。a11y：键盘 focus-within 唤出。源码：TurnSummary.vue。

现 3 组 split-button · hover 副选项 · MD/+Q badge 方案 A 单层 3 icon button · 无 split · 无 badge icon Copy / GitFork / HandHelping（换掉 Upload） +Q 逻辑 按钮=带提问变体 · composer enter=无内容变体 subagent 差异 仅 copy（无 fork/handoff）
① 默认态
这是 assistant 的收尾 summary。完成后文字用 neutral-fg，hover 才显 actions 行。
② streaming
这是 streaming 中的 summary，文字用 neutral-mid（弱化），末尾跟闪烁竖条 cursor
③ hover 显出
hover（或键盘 focus-within）时 actions 行 opacity-100 显出。方案 A：3 个 24px ghost icon 扁平并列，无 sep · 无 badge。
④ fork/handoff hover
fork / handoff hover 时染 accent-soft + text-accent，区别 copy 的中性 hover。视觉上提示「这是会发起 +Q 提问变体的入口」。
⑤ 复制反馈

subagent session（isSubagentVirtualId true）：仅渲染 copy 按钮，无 fork / handoff——关键权限差异。
