§13

动画 · 状态指示 + 微交互

动画分两类：状态指示（spinner/脉冲点/blink——是「状态如何表达」的一部分，不带动画状态就看不出）和 微交互（hover/focus 过渡、展开收起）。两类都在本 spec 标注（duration/easing），大动效（页面切换/引导序列）后出。token 层已有 --duration-fast/normal/slow + --ease。prefers-reduced-motion 全局兜底降级为瞬时。
