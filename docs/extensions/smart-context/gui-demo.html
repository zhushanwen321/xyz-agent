智能上下文压缩 @zhushanwen/pi-smart-context
启用智能压缩
Agent 自决压缩时机 + 分档阈值提醒；关闭后回到 pi 原生压缩行为
压缩模型
生成压缩摘要的模型。选择与当前会话一致的模型将启用同模型模式（KV 缓存命中，成本最低、摘要质量最高）
同模型模式（same-model）：压缩模型与当前会话模型一致。使用完整原始对话（含工具结果，不截断）+ 末尾追加压缩指令，KV 缓存前缀全命中——新增成本仅压缩指令与摘要输出，摘要质量上限最高。
提醒阈值（3 档）
上下文 token 越过某档时提醒 Agent 一次（自行判断是否压缩，不强制）。内建自动压缩仍作为接近窗口上限时的最后防线
K / K / K
排除模型（精准匹配）
命中排除列表的会话模型完全关闭本功能（工具拒绝、不提醒、压缩回落 pi 原生）。按完整 provider/modelId 精准匹配，切换跨界时 Agent 会收到一条可用性变化通知
deepseek/deepseek-chat× + 添加模型
压缩流量计入压缩模型的用量统计（同模型模式下走 KV 缓存，增量成本极低；跨模型模式按所配模型费率计费）。 内建自动压缩触发线（窗口上限 − 16K）保留为最后防线，其压缩执行同样走本扩展逻辑，session 记录带 smart-context 引擎标记。
demo 交互说明：点击顶部开关可预览禁用态（表单置灰）；切换"压缩模型"下拉可预览两种模式的提示条联动——选中与当前会话一致的 GLM-5.2 显示同模型模式（same-model），选中 MiMo v2.5 等其他模型显示跨模型模式（cross-model），选中"未设置"显示跟随当前模型。此为纯前端静态演示，不落盘任何配置。
