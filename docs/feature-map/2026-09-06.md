## 一、新增用户能力：后台命令侧边栏视图 + Drawer 详情

### 功能概述

AI 侧 bash 后台任务此前对用户零可见零可控。本功能打通「runtime 直读 registry.json（跨进程 SSOT）→ WS 拉取/广播 → renderer 原生视图」链路：plugin 区新增「后台命令」L2 tab（三桶筛选 运行中/已结束/全部 + 计数，默认运行中；两行式 item；running 行行内两段式终止；L2 tab badge 与运行中桶计数同源），点击行开 drawer 第 8 个 tab「后台命令」（命令全文可复制 / 元信息 / 输出尾部 2s 跟随 / 终止按钮）；kill 回路带 killing-intent 预写 + extension poller intent 读回，保证终止不惊扰 AI。设计全文 [docs/design/background-task-sidebar-view.md](../design/background-task-sidebar-view.md)，实施计划与单元台账 [background-task-sidebar-view.impl-plan.md](../design/background-task-sidebar-view.impl-plan.md)。

### 关键落点

| 层 | 载体 |
|------|------|
| 协议域 | `packages/shared/src/protocol.ts`（backgroundTask.list/output/kill 3 RPC + `backgroundTask:updated` 广播）· `packages/renderer/src/api/domains/background-task.ts` |
| runtime | `packages/runtime/src/services/background-task/`（registry 读 + 2s mtime 轮询/事件钩子双触发 + kill 五分支矩阵 + tail 字节窗口）· `session-message-handler.ts` / `session-service.ts` 接线 |
| 分桶 SSOT | `packages/renderer/src/lib/background-task-bucket.ts`（分桶/计数/排序/statusIcon 四方同源）+ `useBackgroundTasks` / `useBackgroundTaskBucketFilter`（per-session 分区） |
| 列表视图 | `packages/core/src/extension-host/builtin-contributions.ts`（sidebar.tab 声明）· `packages/ui/src/extension-host/`（NATIVE_VIEWS 注入契约 + L2 badge）· `packages/renderer/src/components/extension/BackgroundTaskListView.vue` |
| Drawer 详情 | `BackgroundTaskDetailPanel.vue`（新）+ DrawerPanel/PanelContainer 第 8 tab（`'bashTask'`）接线 |
| extension（唯一改动 D6-en） | `extensions/universal/base-tool-enhance/src/background/poller.ts`（终态化读回 registry killing intent → reason=killed，UI 代杀不唤醒 AI） |
| i18n | `packages/renderer/src/i18n/locales/{zh-CN,en-US}/{panel,sidebar}.ts`（`panel.sideDrawer.bashTask*` 21 key + `sidebar.backgroundTaskList.*` 18 key；术语裁决：本视图一律「后台命令」，与 subagent 的「后台任务」区分） |
| 测试手册 | [docs/testing/14-background-task-sidebar.md](../testing/14-background-task-sidebar.md)（双侧 data-testid 清单） |
