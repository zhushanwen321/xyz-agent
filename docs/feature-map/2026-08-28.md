## 一、新增架构能力：pi 边界可靠性（语义吸收层四支柱）

### 功能概述

针对 2026-08-27 同日两起同类事故（subagent 派发 429/gc + 思考等级自动变关）的架构级修复：xyz-agent 与 pi 之间补「语义吸收层」——对 pi 私有语义的推断与跨边界承诺只在边界一次吸收，域内只剩确定性。设计全文 [docs/design/pi-boundary-reliability.md](../design/pi-boundary-reliability.md)，决策记录 [ADR-0064](../adr/0064-pi-semantic-absorption-layer.md)。

### 四支柱与落地

| 支柱 | 载体 | 单元 |
|------|------|------|
| 能力注册表 | `packages/runtime/src/services/model-capability.ts`（pi-ai 同源档位计算 + `get_available_models` 在线对账，`supportedLevels` 下发） | U5/U5b |
| 生效回执 | protocol.ts 改状态 RPC（setThinkingLevel / model.switch）reply 回生效值；useModel 弃乐观写；删除 thinkingLevel 30s 兜底轮询 | U6 |
| 确认式送达 | subagent-workflow notify-ledger（持久账本 + notifyId 幂等 + settled 边沿 courier）；outcome 一等字段（completed/failed/cancelled） | U1-U4（切片 1） |
| 漂移守卫 | `docs/pi-semantics.json`（PS-01~16 机器登记）+ `scripts/check-pi-semantics.mjs`（四包版本门禁）+ 探针测试族 6 文件 + `diff-probe-thinking.mjs` + `check_subagent_channels.py` | U7a/U7b |

### 护栏挂载点

- **G1** `check-pi-semantics.mjs`：pre-commit 总闸 + CI invariants（无独立 SKIP_*，总闸兜底）
- **G3** `diff-probe-thinking.mjs`：pre-commit 四文件触发（registry 计算路径 vs pi-ai 同源函数对账）
- **G4** `check_subagent_channels.py`：pre-commit（staged 命中 subagent-workflow 时）+ CI `--all`；deliverAs / `--model` 双白名单 + `g4-allow:` 行级豁免
- **G5** `thinking-level-effective-e2e.test.ts`：REAL_PI_TESTS 分池（凭证机跑，回执保真端到端保险丝）

### 治理登记（U8）

- constraints.json 新增 C-pi-12 / C-pi-13 / C-ext-19 / C-proc-08（共 80 条）；C-build-01 scope 修正为三个 tsup.config.ts 精确路径
- troubleshooting.md：观察项 #1-#5 加 PS 编号互链，新增 #6-#11（PS-01/02/03/05/06/07/09）；历史排查规则新增 closedReason:"gc" 判读 + 模型名大小写漂移致 429 排查路径
- extension-conventions.md：新增「模型引用解析 [MANDATORY]」节 + 「Event handler 消息注入」补可靠性分级段
- TEST-STRATEGY.md：回归基线新增「pi 语义守卫探针族」+ G5 用例归属 + topic 段
- 术语登记：context.md / glossary.md 各 4 条（语义吸收层 / 能力注册表 / 生效回执 / 确认式送达）
- logging-conventions.md：session-delivery warn 出口接 extensionLogger 口径（notify-ledger 三桶可观测性）

### 附带落地（D9 轮询精简，同日）

驻留周期定时器 12 处 → 收敛处置：plugin-host 30s 空转删除、handoff 2s 轮询事件化、flushAll 5s×2 删除、更新检查 20min→60min、skill watch polling 降级化（`XYZ_AGENT_SKILL_WATCH_POLLING=1` 回退）、thinkingLevel 30s 轮询随 U6 删除。判定准则（四类框架）见 [troubleshooting.md](../troubleshooting.md)「周期轮询/兜底定时器的合法性判定」。
