## 一、新增功能：用量统计页（Settings → 用量）

### 功能概述

Settings 第 12 项「用量」页面，展示 Token 消耗、费用估算、缓存命中率等维度的统计面板。数据来源为 pi session 文件的 assistant 消息 usage 逐条累加。

### 架构分层

| 层 | 路径 | 说明 |
|----|------|------|
| **Runtime 服务** | `packages/runtime/src/services/usage/` | UsageStatsService：扫描 session 文件 → 解析 usage → 聚合返回 |
| **共享类型** | `packages/shared/src/usage-stats.ts` | UsageRow / UsageMetrics / UsageStatsResult 类型定义 |
| **RPC 通道** | `packages/shared/src/protocol.ts` | `usage.getStats` 命令注册 |
| **Renderer API** | `packages/renderer/src/api/domains/usage.ts` | 前端调用层 |
| **Renderer 组件** | `packages/renderer/src/components/settings/usage/` | 七组件页面 + aggregate 聚合工具 |

### 组件清单

| 组件 | 职责 |
|------|------|
| `UsagePage.vue` | 编排组件：数据拉取 → 过滤器 → 七子组件分发 |
| `UsageLedger.vue` | 摘要台账行（总 Token / 费用 / 消息数 / 活跃天 / 缓存命中率 / 峰值日） |
| `UsageDailyChart.vue` | 每日堆叠柱状图（手写 SVG，hover tooltip） |
| `UsageHeatCalendar.vue` | 16 周热力日历（分位数 5 档着色） |
| `UsageModelRank.vue` | 模型谱排名条形列表（点击可单看某模型） |
| `UsageProjectRank.vue` | 项目谱排名（微型堆叠条展示 provider 构成） |
| `UsageCacheMix.vue` | 缓存构成（命中/新输入/输出百分比构成条） |
| `UsageDetailTable.vue` | 明细台账（按 provider 分组的可折叠表格） |
| `aggregate.ts` | 前端聚合工具（从 UsageRow[] 切片出七组件视图数据） |

### 边界场景

- 空态（无 session）：引导文案 + 不渲染数据组件
- 费用全 0（订阅制）：费用列 dim 色「—」
- skippedLines > 0：脚注提示跳过行数
- WS 请求失败：错误态 + 重试按钮

### 开发波次

| 波次 | 内容 | 状态 |
|------|------|------|
| W1 | 数据层（UsageStatsService + RPC + 共享类型） | ✅ |
| W2 | 占位页面 + 错误态/空态骨架 | ✅ |
| W3 | 七组件页面 + aggregate 聚合 | ✅ |
| W4 | 真实数据集成 + 视觉打磨 | ✅ |
