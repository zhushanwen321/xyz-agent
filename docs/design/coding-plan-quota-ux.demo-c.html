方案 C · 分步引导

用步骤条把「选类型 → 填参数 → 测试并开启」串起来，每一步只显示当下需要的字段。完成后该步折叠成一行摘要，随时可以点「更改」回去。

这一版最直接地回应「5 种类型参数各不相同」的困扰 —— 用户不需要一次面对所有可能的字段，只看当前类型真正需要的那几个。

优点：新用户不会被字段淹没；「还差哪一步」永远明确；类型差异被步骤天然吸收
代价：比平铺多一次「回看 / 更改」的动作；已熟练的用户可能觉得绕
改动量：中大（新的步骤状态机 + 区块重写）
