### MF-1 三步管线封闭性推演记录（本轮核心问题，判通过）

- **CSI 判定充分性**：ESC `[` 后参数区为 0x30-0x3F、中间字节 0x20-0x2F，与终止字节区 0x40-0x7E 互斥——「最近 ESC 到截点之间无 0x40-0x7E」对 CSI 序列无假阳性/假阴性（截点在序列内必判中）。规则对 CSI 封闭。
- **第③步码点回退后置**：推进（②）与回退（③）顺序声明明确（「最后执行，保证推进后的起点同样安全」），代理对在两个起点上都受保护。封闭。
- **无后续 ESC 残余**：四条件交集登记 + end 全量恢复，r3 已确认，本轮复核登记四要素齐备（量级/恢复/重审/判定），通过。
- **推演出的两处边界**：见上表两条 suggestion——均不击穿「transient 预览 + end 全量快照」的总体安全网，不构成 must-fix。
