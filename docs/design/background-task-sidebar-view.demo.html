后台命令 · 侧边栏插件区展示形态 demo

这是「background bash 任务在侧边栏 plugin 区展示 + 点击 drawer 看详情」的 UI 评审 demo。pi 会话内以后台模式启动的 bash 命令（bt- 前缀任务）会出现在侧边栏「插件」tab 的「后台命令」二级 tab 里；点击任一条目打开右侧 drawer 查看完整命令、元信息与输出尾部。

术语说明：视图命名为「后台命令」——「后台任务」一词已被 Agents tab（subagent）的 i18n 占用（「暂无后台任务」），两者是不同对象（subagent = 后台代理进程；本视图 = 后台 bash 命令），命名必须区分。

设计对齐：列表形态对齐 dev-0.9.15 Agents tab 二级筛选设计（subagent-sidebar-filter，方案 A 迷你凹陷槽）——「运行中 / 已结束 / 全部」三桶 + 默认运行中 + 空桶自适应 + 行内两段式终止（X → ✓）+ tab 角标与运行中桶计数同源，与 Agents tab 视觉语言一致。

任务状态机：running（运行中，计时实时跳动）→ killing（已发 kill 待确认的瞬态）→ exited（终态，reason = natural 自然结束 / timeout 超时 / killed 被终止）；另有 orphaned（属主 pi 进程死亡被收殓）。终态任务保留最近 50 条（LRU 淘汰）。

下方各区块：A 插件区 L2 tab 形态 · B 二级筛选与多状态（可交互） · C 空态三分 · D drawer 详情（点击任一 item 体验） · E 边界情况。

A

插件区 L2 二级 tab「后台命令」

在「插件」一级 tab 内，与现有 todo / goal 并排新增「后台命令」二级 tab；有活跃任务时 tab 上带运行中数量角标。

文件 Agents 插件
怎么看：上方模拟侧边栏「插件」tab 内的 L2TabBar 切换。点击「待办」「目标」可感受 tab 切换；「后台命令」tab 右侧的灰色小圆角标显示当前运行中（running + killing）任务数，随状态实时刷新。

角标语义（与 Agents tab badge 同源）：计数与列表二级筛选的「运行中」桶同源同函数派生（badge 亮 = 有命令在跑 = 默认桶非空），避免 subagent 设计审查抓出的「badge 点亮而默认视图是历史记录」语义断裂。
B

二级状态筛选：运行中 / 已结束 / 全部

列表顶部凹陷槽三桶筛选（对齐 Agents tab 二级筛选范式），默认「运行中」——打开即见在跑的命令，历史不干扰；桶上带计数预告。三行式 item：状态指示 + 命令 + 行内终止；第二行 mono 元信息；第三行输出摘要。点击筛选切换体验。

筛选交互：凹陷槽（bg-input 底 + active 浮起，Agents tab 同范式）；默认「运行中」＝ running + killing；「已结束」＝ exited（成功/失败/超时/被终止）+ orphaned；「全部」＝ 运行中置顶 + 分隔线 + 历史倒序。切桶纯前端过滤，无加载感。

行内终止（两段式）：hover 运行中行右侧出现 X 按钮；第一次点击变为红色 ✓ 确认态，再点一次才真正发 kill（任务转 killing）——不需要打开 drawer 即可终止，与 Agents tab 取消按钮同交互语言。

两行式 item（SessionItem 同构）：第一行 7px 状态 icon + 命令 + 右侧耗时；第二行 mono 小字 pid（终态附 · exit N）+ 右侧 hover 两段式终止钮。状态文字徽标不进列表——icon 即状态（语义色对齐 session：旋转环=运行 / warn 点=终止中·超时 / 绿点=exit 0 / 红点=exit≠0 / 灰点=已终止·孤儿），「成功/失败」与 exit 码信息重复只留 exit 码；输出摘要归 drawer。点击任意条目可打开 drawer（区块 D）。
C

空态三分：全量空 / 运行中空桶 / 已结束空桶

对齐 Agents tab 空态语义：全量空态不渲染筛选条（空 session 下 0 计数槽是纯噪音）；「运行中」空桶给自适应提示 + 一键查看全部（高频场景）；「已结束」空桶仅文案。C2 / C3 可交互。

C1 全量空态：session 从未有后台命令；大图标低透明度 + 两行文案（Agents tab 空态同范式）；无筛选条、无角标。

C2 运行中空桶（默认桶）：全部任务已结束时的默认视图——「没有运行中的后台命令」+ 查看全部 (N) 一键跳转（Agents tab 同款高频引导：跑完回来看一眼 → 一键看历史）。

C3 已结束空桶：只有运行中任务的会话切到「已结束」——仅文案提示，不给多余操作。
D

点击条目 → Drawer 详情

从右侧滑入。完整命令（可复制）· 元信息表 · 输出尾部预览（等宽块）· running 时的「终止任务」按钮（终态无操作按钮）。点击上方任一列表里的条目即可体验。

快捷打开：

drawer 内「终止任务」按钮为两段式：第一次点击变为「确认终止？」，再点一次才真正发送 kill（发送后列表中该任务进入 killing 态）。

E

边界情况

超长命令截断（hover 看全 / 详情看全文）· 多条 running 并发 · 终态任务 LRU 淘汰。

E1 超长命令：列表单行截断（省略号），鼠标悬停 tooltip 展示全文，drawer 详情内完整换行展示。多见于带长参数列表的构建 / 测试命令。

E2 并发 running：同时 3 条 running，各自独立计时；tab 角标显示总数 3。

E3 LRU 淘汰：终态任务按 endedAt 保留最近 50 条，超出淘汰最旧；列表底部显示「已结束 · N / 50」计数提示淘汰水位。
