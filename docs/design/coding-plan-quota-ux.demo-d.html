方案 D · 摘要 + 折叠编辑

平时收成一行摘要（类型 · 开关 · 当前用量），点「编辑」才展开完整配置。展开后的编辑体就是方案 B 那一套。

这一版解决的是另一个问题：Provider 设置页是一个可展开的列表，如果每个 provider 都铺开一整块额度配置，页面会非常长 —— 而绝大多数时候用户只是「看一眼有没有配额」。

优点：设置页信噪比最高；已配好的 provider 不再占屏；摘要本身就能看到用量
代价：首次配置多一次展开；摘要里的用量要额外拉取或读缓存
改动量：中（在方案 B 之上加一层折叠壳）
